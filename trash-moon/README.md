# 쓰레기 행성 (프로토타입)

우주로 보낸 쓰레기를 먹고 무거워진 행성이 지구로 끌려오고, 끝내 지구가 멸망하는 방치형 게임입니다. 화면은 "만약 달이 지구에 떨어지면" 쇼츠처럼 위쪽 검은 띠에 **지구까지 ○○○ km**, 아래에 강가의 빌딩 숲과 하늘의 행성입니다.

## 하는 법

- **[쓰레기 발사!]** 를 누르면 쓰레기를 한 번 보냅니다(처음엔 1톤).
- 보낸 쓰레기만큼 **처리비(원)** 를 받습니다(1톤 = 1원). 처리비로:
  - **봉투 키우기**: 한 번에 보내는 양 두 배
  - **발사대 10종**: 가만히 있어도 계속 보냄. 같은 발사대는 살 때마다 값 ×1.15, 25·50·100·200개 모으면 그 발사대 생산 ×2

  | 발사대 | 값 | 초당 |
  |---|---|---|
  | 봉투 던지기 부대 | 15 | 0.15톤 |
  | 쓰레기 트럭 점프대 | 100 | 1톤 |
  | 거대 새총 | 1,100 | 11톤 |
  | 쓰레기 로켓 | 1.2만 | 120톤 |
  | 우주 발사 기지 | 13만 | 1,300톤 |
  | 우주 엘리베이터 | 140만 | 1.4만톤 |
  | 매립지 통째로 발사 | 2,000만 | 20만톤 |
  | 폐허 도시 발사 | 3.3억 | 330만톤 |
  | 바다 쓰레기섬 견인 | 50억 | 5,000만톤 |
  | 쓰레기 산맥 대포 | 750억 | 7.5억톤 |

  다음 발사대는 값의 절반을 모으면 공개됩니다.
- 앱을 꺼 둔 동안(최대 8시간)에도 발사대가 계속 보냅니다.

## 물리 계산

- **크기**: 행성은 실제 천체의 반지름·질량을 따라 자랍니다(명왕성 1,188km·지구 질량의 0.2% → 목성 69,911km·318배, 단계 사이는 로그로 이어짐). 하늘에 보이는 크기는 각반지름 **θ = asin(R/D)** 를 화각 60° 카메라로 비춘 **화면 반지름 = 초점거리 × tan θ** 입니다. 그래서 오랫동안 하늘의 밝은 점이다가 가까워지면 급격히 커집니다(처음 보름달의 0.7배 → 충돌 직전 250배 이상, 화면보다 큼).
- **다가오는 방식**: 정지 상태 거리 D₀ = 384,400km에서 지구로 떨어지는 **자유 낙하 궤적**을 따릅니다. 진행도만큼 낙하 시간이 흐른 자리(t ∝ √(x(1−x)) + arccos√x, x = D/D₀)에 있어서, 처음엔 거의 그대로이다가 끝에서 급격히 빨라집니다. **"지구까지"는 두 천체 표면 사이 거리**이고, 0이 되면 충돌합니다.
- **접근 속도**: **v = √(2G(M지구 + M행성)(1/D − 1/D₀))**. 처음 0m/s → 수백 m/s → 해왕성급에서 약 4km/s → 맞닿을 때 약 52km/s(목성 탈출 속도 59.5km/s보다 조금 느림). 위쪽 띠에 접근 속도, 지구 대비 질량, 크기 등급이 나옵니다.
- **망원경**: 행성이 아직 점일 때는 오른쪽 위 둥근 화면에 천문대 망원경 영상으로 확대해 보여 줍니다(행성이 충분히 커지면 사라짐).

## 뉴스 특보

지구까지 375,000 · 365,000 · 350,000 · 320,000 · 280,000 · 240,000 · 200,000 · 160,000 · 120,000 · 80,000 · 50,000 · 25,000 · 10,000 · 2,000km를 지날 때마다 **KBN 뉴스특보**가 하늘 아래쪽에 뜹니다. 앵커가 말하며(입 모양, 눈 깜빡임, 자막) 그 순간의 계산값(거리, 접근 속도, 지구 대비 질량, 보름달의 몇 배 크기)을 전하고, 뒤쪽 모니터에는 천문대 생중계 영상이 나옵니다. 누르면 닫히고, 한 번 본 방송은 다시 나오지 않습니다(새 지구에서는 처음부터).

## 다가오는 행성 (사실적인 그래픽)

- 보낸 쓰레기가 **1,000억 톤**이 되면 충돌합니다(진행도는 보낸 양의 자릿수, 위 물리 계산 참고).
- **행성은 실제 천체 지도(사진 기반)를 입혀 WebGL로 그립니다.** 쓰레기를 먹을수록 실제 크기 순서대로 바뀝니다(상단에 "크기 ○○급", 바뀔 때 서서히 섞임):

  명왕성 → 유로파 → 달 → 이오 → 수성 → 타이탄 → 가니메데 → 화성 → 금성 → 해왕성 → 천왕성(희미한 고리) → 토성(고리) → 목성

  - 공기 없는 천체(달·수성·명왕성 등)는 가장자리까지 고르게 밝고(로멜-젤리거 반사), 표면 밝기로 요철을 만들어 충돌구가 입체로 보입니다.
  - 가스 행성은 명암 경계가 부드럽고 가장자리가 어두워지며(주연 감광), 대기가 테두리에서 빛납니다. 타이탄은 두꺼운 주황 안개.
  - 토성 고리는 행성 그림자를 받고, 행성 표면에도 고리 그림자가 집니다.
  - 천천히 자전하고, 화면 해상도 그대로(최대 2048px) 그려서 커져도 흐려지거나 깍두기가 되지 않습니다.
  - 지구에서 보는 하늘이라, 밝은 낮에는 그늘진 쪽이 하늘빛에 묻히고 작을 때는 대기 너머로 흐릿합니다. 하늘이 어두워질수록 또렷해집니다.
  - 지도는 단계마다 필요한 것만 불러옵니다(장당 30~570KB). WebGL이 안 되는 기기에서는 색이 있는 둥근 점으로 보입니다.
- **배경**: 해와 햇무리가 있는 하늘, 대기에 흐려지는 세 겹의 빌딩 숲, 그늘진 뭉게구름, 도시가 비치고 햇빛이 반짝이는 강.
- **다가올수록**: 행성이 해를 가려 하늘이 어두워지고 낮에 별이 보임 → 오로라 → 강물이 차오름 → 지진으로 빌딩이 하나씩 무너지며 먼지 → 하늘이 붉어지고 불덩이 운석이 떨어져 불이 나고 연기가 피어오름 → 목성급 행성이 조석 마찰로 달아올라 밤쪽이 붉게 빛남.
- **충돌**: 행성이 하늘을 덮고 → 하얀 섬광 → 우주에서 본 지구(실제 지구 지도)에 달아오른 목성이 부딪혀 지구가 갈라지며 흩어집니다 → **지구 멸망**.
- **새 지구에서 다시**: 처음부터 다시 하되 모든 생산과 발사가 영구 ×2.

## 밸런스

모든 발사대의 회수 기간(값 ÷ 초당 생산)이 100초 안팎이라, 위 단계일수록 한 번에 크게 늘어납니다. 가장 효율 좋은 것을 사며 초당 3번 누르는 가상 플레이어 기준 첫 지구 멸망까지 약 50분(`game.test.js`에서 40~70분 안인지 확인). 조정 값은 `logic.js` 맨 위(`END_MASS`, `COST_GROWTH`, `MILESTONES`, `LAUNCHERS`).

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=5'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 발사대, 생산, 처리비, 물리(천체 반지름·질량, 자유 낙하 거리, 접근 속도, 각크기), 뉴스 특보 문구, 꺼 둔 동안의 진행, 새 지구(×2), 저장
globe.js       → WebGL 행성 렌더러(지도 입히기, 요철, 반사, 대기, 고리와 그림자, 낮 하늘 투과)
textures/      → 행성 지도(jpg), 토성 고리(png), 출처
game.test.js   → 로직 테스트
index.html     → 화면 전체 (하늘·도시·강·구름, 로켓, 운석·불·연기, 망원경, 뉴스 스튜디오와 앵커, 충돌 연출, 발사대 목록)
```
