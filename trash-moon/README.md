# 쓰레기 행성 (프로토타입)

우주로 보낸 쓰레기를 먹고 무거워진 행성이 지구로 끌려오고, 끝내 지구가 멸망하는 방치형 게임입니다. 화면은 "만약 달이 지구에 떨어지면" 쇼츠처럼 위쪽 검은 띠에 **지구까지 ○○○ km**, 아래에 강가의 빌딩 숲과 하늘의 행성입니다.

## 하는 법

- **[쓰레기 발사!]** 를 누르면 쓰레기를 한 번 보냅니다(처음엔 1톤).
- 보낸 쓰레기만큼 **처리비(원)** 를 받습니다(1톤 = 1원). 처리비로:
  - **봉투 키우기**: 한 번에 보내는 양 두 배
  - **발사대 10종**: 가만히 있어도 계속 보냄. 같은 발사대는 살 때마다 값 ×1.15, 25·50·100·200개 모으면 그 발사대 생산 ×2

  | 발사대 | 값 | 초당 |
  |---|---|---|
  | 봉투 던지기 부대 | 15 | 0.15톤 |
  | 쓰레기 트럭 점프대 | 100 | 1톤 |
  | 거대 새총 | 1,100 | 11톤 |
  | 쓰레기 로켓 | 1.2만 | 120톤 |
  | 우주 발사 기지 | 13만 | 1,300톤 |
  | 우주 엘리베이터 | 140만 | 1.4만톤 |
  | 매립지 통째로 발사 | 2,000만 | 20만톤 |
  | 폐허 도시 발사 | 3.3억 | 330만톤 |
  | 바다 쓰레기섬 견인 | 50억 | 5,000만톤 |
  | 쓰레기 산맥 대포 | 750억 | 7.5억톤 |

  다음 발사대는 값의 절반을 모으면 공개됩니다.
- 앱을 꺼 둔 동안(최대 8시간)에도 발사대가 계속 보냅니다.

## 다가오는 행성

- 질량이 **1,000억 톤**이 되면 충돌합니다. 거리는 질량의 자릿수로 줄어서, 처음 몇 톤에도 눈에 띄게 다가오고 끝으로 갈수록 무거워집니다.
- **그래픽**: 기기의 실제 해상도로 그립니다. 행성이 커지면 디테일이 늘어날 뿐, 픽셀이 커지지 않습니다.
- **행성**: 쓰레기 덩어리가 아니라, 쓰레기를 먹고 자라는 아름다운 사파이어빛 가스 행성입니다. 날아간 쓰레기는 빛 꼬리를 끌며 올라가 행성 둘레를 돌다 삼켜지고(삼킬 때 살짝 부풂), 먹은 쓰레기가 반짝이는 고리가 됩니다.
- **코즈믹 호러**: 다가올수록
  - 폭풍이 소용돌이치다(35%) → 눈꺼풀이 열리며 **거대한 눈**이 되어(55%~) 도시를 내려다보고, 가끔 깜빡이고, 가까울수록 동공이 가늘어집니다
  - 하늘이 어두워지며 낮인데 별이 보이고, 행성이 숨 쉬듯 맥동하고, 눈에서 **빛나는 핏줄**이 심장 박동처럼 뜁니다
  - 구름이 행성으로 빨려 올라가고, 강물이 차오르고, 지진에 빌딩이 하나씩 무너지고, 불덩이 운석이 떨어집니다
  - 끝에는 행성에서 **빛의 촉수**가 지구로 뻗어 내려오고, 하늘이 핏빛이 됩니다
  - 낮은 울음소리, 심장 박동 소리
- **충돌**: 행성이 하늘을 삼키고 → 하얗게 번쩍 → 우주에서 본 지구가 조각나 흩어집니다 → **지구 멸망**(걸린 시간, 보낸 쓰레기).
- **새 지구에서 다시**: 처음부터 다시 하되 모든 생산과 발사가 영구 ×2(부순 지구마다 두 배씩).

## 밸런스

모든 발사대의 회수 기간(값 ÷ 초당 생산)이 100초 안팎이라, 위 단계일수록 한 번에 크게 늘어납니다. 가장 효율 좋은 것을 사며 초당 3번 누르는 가상 플레이어 기준 첫 지구 멸망까지 약 50분(`game.test.js`에서 40~70분 안인지 확인). 조정 값은 `logic.js` 맨 위(`END_MASS`, `COST_GROWTH`, `MILESTONES`, `LAUNCHERS`).

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=2'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 발사대, 생산, 처리비, 진행도→거리·크기, 속보, 꺼 둔 동안의 진행, 새 지구(×2), 저장
game.test.js   → 로직 테스트
index.html     → 화면 전체 (실제 해상도로 그리는 도시·강·구름·행성(눈, 핏줄, 고리, 촉수), 날아가는 쓰레기, 운석, 충돌 연출, 발사대 목록)
```
