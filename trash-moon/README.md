# 쓰레기 행성 (프로토타입)

우주로 보낸 쓰레기를 먹고 무거워진 행성이 지구로 끌려오고, 끝내 지구가 멸망하는 방치형 게임입니다. 화면은 "만약 달이 지구에 떨어지면" 쇼츠처럼 위쪽 검은 띠에 **지구까지 ○○○ km**, 아래에 강가의 빌딩 숲과 하늘의 행성입니다.

## 하는 법

- **[쓰레기 발사!]** 를 누르면 쓰레기를 한 번 보냅니다(처음엔 1톤).
- 보낸 쓰레기만큼 **처리비(원)** 를 받습니다(1톤 = 1원). 처리비로:
  - **봉투 키우기**: 한 번에 보내는 양 두 배
  - **발사대 10종**: 가만히 있어도 계속 보냄. 같은 발사대는 살 때마다 값 ×1.15, 25·50·100·200개 모으면 그 발사대 생산 ×2

  | 발사대 | 값 | 초당 |
  |---|---|---|
  | 봉투 던지기 부대 | 15 | 0.15톤 |
  | 쓰레기 트럭 점프대 | 100 | 1톤 |
  | 거대 새총 | 1,100 | 11톤 |
  | 쓰레기 로켓 | 1.2만 | 120톤 |
  | 우주 발사 기지 | 13만 | 1,300톤 |
  | 우주 엘리베이터 | 140만 | 1.4만톤 |
  | 매립지 통째로 발사 | 2,000만 | 20만톤 |
  | 폐허 도시 발사 | 3.3억 | 330만톤 |
  | 바다 쓰레기섬 견인 | 50억 | 5,000만톤 |
  | 쓰레기 산맥 대포 | 750억 | 7.5억톤 |

  다음 발사대는 값의 절반을 모으면 공개됩니다.
- 앱을 꺼 둔 동안(최대 8시간)에도 발사대가 계속 보냅니다.

## 다가오는 행성 (사실적인 그래픽)

- 질량이 **1,000억 톤**이 되면 충돌합니다. 거리는 질량의 자릿수로 줄어서, 처음 몇 톤에도 눈에 띄게 다가오고 끝으로 갈수록 무거워집니다.
- 모든 그림을 기기의 실제 해상도로 그립니다(도트 없음). 행성이 커지면 디테일이 늘어날 뿐 흐려지거나 깍두기가 되지 않습니다.
- **행성은 쓰레기를 먹을수록 실제 행성처럼 바뀝니다**(상단에 "크기 ○○급" 표시, 바뀔 때 서서히 섞임):

  | 진행 | 모습 |
  |---|---|
  | 처음 | **달**: 회색 표면, 어두운 바다, 수백 개의 충돌구 |
  | 30% | **화성**: 녹슨 붉은 땅, 어두운 지대, 큰 협곡, 극관 |
  | 42% | **금성**: 두꺼운 크림색 구름 |
  | 54% | **해왕성**: 짙은 파랑, 대흑점과 흰 구름 |
  | 66% | **토성**: 연한 금빛 띠와 카시니 간극이 있는 고리 |
  | 80% | **목성**: 소용돌이치는 띠와 대적점. 끝 무렵엔 조석 마찰로 달아올라 밤쪽이 붉게 빛남 |

  표면 지도는 잡음으로 만들어 공 모양으로 투영하고, 해가 비추는 쪽만 밝게, 가장자리는 어둡게, 대기가 있는 행성은 테두리가 빛납니다. 천천히 자전합니다. 낮 하늘에서는 대기 너머로 흐릿하게 보이다가 하늘이 어두워질수록 또렷해집니다.
- **배경**: 해와 햇무리가 있는 하늘, 대기에 흐려지는 세 겹의 빌딩 숲(유리 빌딩·콘크리트 빌딩·첨탑), 그늘진 뭉게구름, 도시가 비치고 햇빛이 반짝이는 강.
- **다가올수록**: 행성이 해를 가려 하늘이 어두워지고 낮에 별이 보임 → 오로라 → 강물이 차오름 → 지진으로 빌딩이 하나씩 무너지며 먼지 → 하늘이 붉어지고 불덩이 운석이 떨어져 불이 나고 연기가 피어오름. 낮은 땅울림 소리.
- 쓰레기는 로켓처럼 연기 꼬리를 남기며 행성으로 날아갑니다.
- **충돌**: 행성이 하늘을 덮고 → 하얀 섬광 → 우주에서 본 지구에 달아오른 목성급 행성이 부딪혀, 맞닿은 곳이 빛나고 지구가 갈라져 녹은 속을 드러내며 흩어집니다 → **지구 멸망**.
- **새 지구에서 다시**: 처음부터 다시 하되 모든 생산과 발사가 영구 ×2(부순 지구마다 두 배씩).

## 밸런스

모든 발사대의 회수 기간(값 ÷ 초당 생산)이 100초 안팎이라, 위 단계일수록 한 번에 크게 늘어납니다. 가장 효율 좋은 것을 사며 초당 3번 누르는 가상 플레이어 기준 첫 지구 멸망까지 약 50분(`game.test.js`에서 40~70분 안인지 확인). 조정 값은 `logic.js` 맨 위(`END_MASS`, `COST_GROWTH`, `MILESTONES`, `LAUNCHERS`).

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=3'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 발사대, 생산, 처리비, 진행도→거리·크기·행성 종류, 속보, 꺼 둔 동안의 진행, 새 지구(×2), 저장
planets.js     → 실제 행성 표면 지도 만들기(달·화성·금성·해왕성·토성·목성·지구), 공 모양 투영과 빛, 토성 고리
game.test.js   → 로직 테스트
index.html     → 화면 전체 (하늘·도시·강·구름, 로켓, 운석·불·연기, 충돌 연출, 발사대 목록)
```
