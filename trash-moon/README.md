# 쓰레기 행성 (프로토타입)

쓰레기를 우주로 보낼수록 쓰레기 행성이 무거워져 지구로 끌려오고, 끝내 지구가 멸망하는 방치형 게임입니다. 화면은 "만약 달이 지구에 떨어지면" 쇼츠처럼 위쪽 검은 띠에 **지구까지 ○○○ km**, 아래에 강가의 빌딩 숲과 하늘의 행성입니다.

## 하는 법

- **[쓰레기 발사!]** 를 누르면 쓰레기를 한 번 보냅니다(처음엔 1톤).
- 보낸 쓰레기만큼 **처리비(원)** 를 받습니다(1톤 = 1원). 처리비로:
  - **봉투 키우기**: 한 번에 보내는 양 두 배
  - **발사대 10종**: 가만히 있어도 계속 보냄. 같은 발사대는 살 때마다 값 ×1.15, 25·50·100·200개 모으면 그 발사대 생산 ×2

  | 발사대 | 값 | 초당 |
  |---|---|---|
  | 봉투 던지기 부대 | 15 | 0.15톤 |
  | 쓰레기 트럭 점프대 | 100 | 1톤 |
  | 거대 새총 | 1,100 | 11톤 |
  | 쓰레기 로켓 | 1.2만 | 120톤 |
  | 우주 발사 기지 | 13만 | 1,300톤 |
  | 우주 엘리베이터 | 140만 | 1.4만톤 |
  | 매립지 통째로 발사 | 2,000만 | 20만톤 |
  | 폐허 도시 발사 | 3.3억 | 330만톤 |
  | 바다 쓰레기섬 견인 | 50억 | 5,000만톤 |
  | 쓰레기 산맥 대포 | 750억 | 7.5억톤 |

  다음 발사대는 값의 절반을 모으면 공개됩니다.
- 앱을 꺼 둔 동안(최대 8시간)에도 발사대가 계속 보냅니다.

## 다가오는 행성

- 질량이 **1,000억 톤**이 되면 충돌합니다. 거리는 질량의 자릿수로 줄어서, 처음 몇 톤에도 눈에 띄게 다가오고 끝으로 갈수록 무거워집니다(12톤이면 약 32.7만km).
- 행성은 처음엔 점이었다가 점점 커져 화면을 덮습니다. 표면은 페트병·캔·비닐·타이어 같은 쓰레기 조각 무늬입니다.
- 다가올수록: 구름이 행성 쪽으로 끌려가고(절반쯤부터) → 강물이 차오르고 → 지진이 나며 빌딩이 하나씩 무너지고 → 하늘이 붉어지고 쓰레기 운석이 떨어져 도시에서 터집니다. 아래 **속보** 띠 문구도 바뀝니다.
- **충돌**: 행성이 화면을 집어삼키고, 도시가 무너지고, 하얗게 번쩍인 뒤 우주에서 본 지구가 조각나 흩어집니다 → **지구 멸망!**(걸린 시간, 보낸 쓰레기).
- **새 지구에서 다시**: 처음부터 다시 하되 모든 생산과 발사가 영구 ×2(부순 지구마다 두 배씩).

## 밸런스

모든 발사대의 회수 기간(값 ÷ 초당 생산)이 100초 안팎이라, 위 단계일수록 한 번에 크게 늘어납니다. 가장 효율 좋은 것을 사며 초당 3번 누르는 가상 플레이어 기준 첫 지구 멸망까지 약 50분(`game.test.js`에서 40~70분 안인지 확인). 조정 값은 `logic.js` 맨 위(`END_MASS`, `COST_GROWTH`, `MILESTONES`, `LAUNCHERS`).

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=1'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 발사대, 생산, 처리비, 진행도→거리·크기, 속보, 꺼 둔 동안의 진행, 새 지구(×2), 저장
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 도시·강·구름·쓰레기 행성, 날아가는 쓰레기, 운석, 충돌 연출, 발사대 목록)
```
