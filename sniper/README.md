# 스나이퍼

옥상에서 도시를 내려다보며, 브리핑의 인상착의(모자·옷 색·소지품)와 같은 표적을 군중 속에서 찾아 한 발에 끝내는 스테이지 미션 게임. 코드로 그린 픽셀 아트.

## 하는 법
- 화면을 누르면 조준경. 끌어서 조준, 🔍로 ×4 / ×8.
- 😮‍💨 숨 참기를 누르고 있으면 흔들림이 거의 멈춰요(약 3.5초). 너무 오래 참으면 숨이 차서 한동안 크게 흔들려요.
- 거리에 따라 총알이 떨어지고(영점 250m), 바람에 밀려요. 조준경 아래에 거리, 낙차, 편류가 미터와 밀로 나와요. 조준선의 점 한 칸이 1밀이에요.
- 걷는 표적은 총알이 날아가는 동안 움직여요. 앞을 겨누세요.
- 표적을 맞히면 슬로모션 총알 카메라. 머리면 헤드샷.
- 놓치면 거리 사람들은 흩어지고(표적은 화면 밖으로 달아남), 창가 표적은 숨었다가 다른 창문에 나타나요. 민간인을 맞히면 실패. 총알 3발.
- 별: 성공 ★, 첫 발 또는 머리 ★, 첫 발 머리 ★.

## 스테이지
15개 고정 + 그 뒤로 계속. 거리(150~235m) → 맞은편 창가(380~460m) → 먼 옥상(640~800m), 낮 → 해질녘 → 밤(야간 투시경). 뒤로 갈수록 군중·닮은 사람·바람이 늘고 제한 시간이 생겨요. 1~3은 예상 탄착점이 보이는 연습.

## 탄도
- 아트 픽셀 하나 = 0.398밀리라디안(200m의 175cm 사람이 22픽셀).
- 비행 시간 t = d/900 × (1 + d/4000), 낙차 = ½gt² − 영점 보정, 편류 = 바람 × (t − d/900) × 2.2.
