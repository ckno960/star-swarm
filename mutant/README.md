# 뮤턴트 시티

몸을 바꾸는 변이체가 되어 3D 도시를 마음대로 누비는 샌드박스 액션. 낮은 해상도로 그려 픽셀이 보이는 레트로 3D(three.js).

## 하는 법
- 왼쪽 아래를 끌어 이동, 화면을 끌어 시점 돌리기.
- ⤴ 점프. 벽 쪽으로 밀면 벽을 달려 올라가 옥상으로. 공중에서 점프를 누르고 있으면 활공. 높은 데서 떨어지면 땅이 울려 주변이 날아가요.
- 🩸 흡수: 사람을 흡수해 체력과 EP. 군인을 흡수하면 군인으로 변장(군인들이 공격하지 않음). 군인 앞에서 공격·벽 타기·활공을 하면 들켜요.
- 👊 공격, 🔄 무기(주먹 · 칼날 팔 · 거대 주먹), 💨 돌진(공중에서도).
- ⚠ 경계 0~5. 군인 눈에 띄지 않으면 내려가요. 3단계부터 헬기가 출동해 주위를 돌며 쏴요. 가까이 뛰어올라 때리면 격추.
- 🔴 감염 둥지에서 감염체가 나와 사람과 군인을 공격해요. 둥지를 부수면 +120 EP, 30초 뒤 다른 곳에 새 둥지.
- 🧬 진화: EP로 체력·공격력·이동·재생 강화. 쓰러지면 EP 20%를 잃고 옥상에서 다시 깨어나요.
- 컴퓨터: WASD 이동, 스페이스 점프, J 공격, K 흡수, L(또는 Shift) 돌진, Q 무기.

원작 게임(프로토타입)의 재미 요소에서 영감을 받은 오리지널 게임이에요. 원작의 이름·캐릭터는 쓰지 않았어요.

## 파일
```
logic.js        → 무기·적 수치, 흡수·변장, 경계 단계, 체력·재생·부활, 진화, 저장
index.html      → 3D 도시, 플레이어(벽 타기·활공·돌진), 시민·군인·감염체·둥지·헬기, 조작, 소리
models/person.glb → 플레이어 모델(Blender, ../sniper3d/tools/build_models.py)
vendor/         → three.js 0.170 (MIT)
game.test.js    → node --test
```
