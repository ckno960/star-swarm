# 파칭코 타이쿤

구슬이 저절로 떨어지는 파칭코 판으로 돈을 버는 방치형 게임.

## 하는 법
- 구슬이 자동으로 떨어져 못에 튕기다가 아래 9칸 중 하나에 들어가고, 그 칸의 배수만큼 돈을 벌어요. 판을 누르면 그 자리에 구슬을 더 떨어뜨려요.
- **럭키 램프**: 불 켜진 칸이 1.2초마다 옆으로 옮겨 가요. 그 칸에 들어가면 ×8.
- **★ 스타트 구멍**(판 가운데): 들어가면 ×3을 받고 릴이 한 번 돌아요(보류 최대 4개).
- **릴**: 숫자 셋이 맞으면 잭팟(구슬 값 ×150 보너스 + 구슬 40개) + **피버** 12초(수익 ×5 이상, 발사 2배). 앞 두 개만 맞으면 "리치" 연출 뒤 아깝게 빗나가요. 기본 잭팟 확률 1/30.
- **업그레이드**: 구슬 가치(25·50·100레벨마다 ×2), 자동 발사, 황금 구슬(×10), 행운(잭팟 확률 최대 1/8.4), 피버 배수.
- **가게 확장**(환생): 이번 가게에서 5만 원 넘게 벌면 메달을 받고 처음부터. 메달 하나마다 수익 +10%.
- 꺼 둬도 최대 8시간 동안 절반 속도로 돈이 쌓여요.

## 파일
```
logic.js      → 칸 배수·럭키 램프, 업그레이드, 릴 추첨·잭팟·피버, 환생, 오프라인, 저장
index.html    → 판 물리(못·벽·칸), 릴 연출, 화면, 소리
game.test.js  → node --test
```
평균 배수(EXPECTED_MULT)는 실제 판에서 구슬 5천 개를 떨어뜨려 잰 값이에요(브라우저 콘솔 `__pk.measure(5000)`).
