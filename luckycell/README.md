# 럭키 셀

독방에 갇혀 슬롯머신으로 기한마다 불어나는 빚을 갚는 슬롯 로그라이크. 직접 레버를 당겨 돌려요(클로버핏에서 영감을 받은 오리지널 게임).

## 하는 법
- **돌리기**: 오른쪽 레버를 아래로 끌어당기거나 SPIN. 릴이 왼쪽부터 하나씩 멈추고, 한 줄이 맞아 가면 뜸을 들여요. 돌아가는 중에 기계를 누르면 빨리 감기.
- **패턴**(5×3): 가로 3(×1)·4(×3)·5(×6), 세로(×1), 대각선(×1), 지그재그(×5), 15칸 모두 같으면 잭팟(×30). 배당 = 무늬 값 × 패턴 배수.
- **무늬**: 🍋🍒 10, 🍀 15, 🔔 20, 💎 30, 7️⃣ 50. 💀이 가로로 3개 이어지면 저주(코인 절반).
- **기한**: 한 기한은 3라운드, 라운드마다 스핀 5번. 3라운드가 끝날 때 빚을 갚아요. 빚은 60에서 시작해 기한마다 약 1.62배.
- **상점**(라운드 사이): 부적 3개 중에 골라 사요(칸 5개, 반값에 되팔기, 다시 뽑기). 2라운드부터는 빚을 미리 갚고 남은 라운드를 건너뛰면 보너스.
- **부적 20종**: 무늬 값·확률·배당, 패턴 배수, 스핀 추가, 이자, 첫·마지막 스핀 배수, 꽝 쌓임, 조커(와일드), 액막이, 복권, 거울.
- **환생**: 빚을 못 갚으면 끝. 넘긴 기한 수에 따라 ⭐별(1, 3, 6, 10…, 최소 1)을 받아 시작 코인·스핀·부적 칸·할인·무료 다시 뽑기를 영구 강화해요.

## 파일
```
logic.js      → 무늬·패턴 찾기, 배당, 부적, 라운드·기한·빚, 상점, 환생, 저장
index.html    → 기계·레버·릴 연출, 상점·결과·환생 화면, 소리
game.test.js  → node --test
```
