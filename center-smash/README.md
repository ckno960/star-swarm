# 정중앙 스매시 (프로토타입)

바늘이 정중앙에 올 때 뛰어올라, 최고점에서 내려찍어 마을 → 도시 → 나라 → 행성을 차례로 부수는 타이밍 게임입니다. 화면 구성은 무한의 계단처럼 세로 화면, 위쪽 시간 막대와 큰 점수, 아래쪽 큰 버튼 하나입니다.

## 규칙

- **점프**: 아래 막대에서 바늘이 좌우로 움직입니다. 정중앙에 가까울 때 누를수록 **높이 뛰고 피해도 큽니다**.
  - PERFECT(가운데 ±8%): 최고 높이, 피해 ×3 · GREAT(±22%) · GOOD(±50%) · MISS(조금만 뜀)
- **내려찍기**: 공중에서 한 번 더 누르면 그 자리에서 내리꽂습니다. **최고점에 가까울수록** 피해가 커집니다.
  - PERFECT(최고점 ±0.07초) ×2 · GREAT(±0.16초) ×1.5 · GOOD(±0.32초) ×1.15 · 너무 빠르거나 늦으면 ×1
  - 누르지 않으면 그냥 떨어져서 기본 피해만 줍니다.
- 점프할 때 **왼쪽 게이지**가 높이를 보여 주고, **빨간 선**이 이번 점프의 최고점입니다. 최고점 근처에서는 선이 깜빡이고 높이 숫자가 노랗게 바뀝니다.
- 점프나 내려찍기 중 하나라도 PERFECT면 **콤보**가 이어져 피해가 10%씩 늘어납니다(최대 +50%).
- 위쪽 **시간 막대**가 다 닳기 전에 대상을 부숴야 합니다. 마지막 점프 중에 시간이 끝나면 그 착지까지는 인정합니다.
- **버튼은 하나**입니다. 땅에서는 [점프], 뛰는 순간 노란 [찍기]로 바로 바뀌고, 착지하면 다시 [점프]로 돌아옵니다. 누를 때가 되면 반짝입니다. 화면을 눌러도 되고, PC는 Space/↑/↓, Esc 일시정지.

## 진화와 점프 높이

지역마다 4번 진화해 몸이 커지고, 세상이 그만큼 작아 보입니다. 같은 화면 구도에서 숫자 단위가 커집니다.

| 지역 | 주인공 | 최고 점프(첫 대상 → 보스) | 대상 |
|---|---|---|---|
| 마을 | 사람 | 6m → 15m | 나무 오두막, 풍차, 대장간, 마을 교회, 촌장의 저택 |
| 도시 | 거인 | 240m → 680m | 편의점, 아파트, 백화점, 방송국 타워, 초고층 빌딩 |
| 나라 | 거신 | 16km → 48km (성층권, 하늘이 검어지고 별이 보임) | 국경 요새, 왕궁, 화산, 설산, 대륙 수도 |
| 행성 | 우주 거신 | 3만km → 12만km (행성이 점처럼 작아짐) | 달, 화성, 금성, 토성, 목성 |

높이 뛰면 카메라가 주인공을 따라 **멀어지며 축소**되고(최대 수십 배), 내려올 때 다시 확 당겨집니다. 지역 보스를 부수면 진화 연출(빛나며 커짐 → 하얗게 번쩍 → 커진 몸에서 작아진 세상이 드러남)이 나옵니다.

## 연출

- 도약: 웅크렸다 늘어나는 몸, 지붕 파편과 먼지, 충격파, 높이 뛸수록 공중제비(1~2바퀴), 잔상, 속도선
- 낙하: 머리부터 내리꽂는 자세, 높은 곳에서 찍으면 불꽃(대기권 돌입), 속도선, 카메라가 빠르게 당겨짐
- 착지: 잠깐 멈춤(히트스톱), 화면 흔들림, 번쩍임, 충격파, 파편·먼지, 피해 숫자. 대상은 맞을수록 금이 가고 깎여 낮아짐
- **PERFECT**: 금빛 큰 문구가 튀어 오르고, 점프 때는 금빛 고리·빛줄기와 잠깐 느려지는 슬로 모션, 최고점 찍기 때는 0.26초 시간 정지 + 화면 당김 + 금빛 폭발, 착지 때는 금빛 빛줄기와 큰 금빛 피해 숫자. 잔상도 금빛이 됩니다.
- 부수면 건물은 땅속으로 무너져 내리고, 행성은 폭발합니다.
- 소리(효과음 합성)와 진동은 설정에서 끌 수 있습니다.

## 밸런스

대상 체력은 스테이지마다 늘고(보스 ×1.4), 바늘은 점점 빨라집니다(초당 0.55 → 1.12 왕복). 계산으로 확인한 기준(`game.test.js`):
- 점프 GREAT + 최고점 GREAT를 계속하면 모든 스테이지를 시간 안에 깸
- 대충 누르면(가운데에서 60% 벗어남, 찍기 없음) 어느 스테이지도 못 깸

조정 값은 `logic.js` 맨 위(판정 범위, 배율)와 `stageInfo`(체력, 시간, 바늘 속도), `REGIONS`(점프 높이)에 있습니다.

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=1'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 판정, 점프 높이·체공 곡선, 최고점 판정, 피해, 콤보, 스테이지, 저장
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 카메라 확대·축소, 연출, 소리, 메뉴)
```
