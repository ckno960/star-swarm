# 정중앙 스매시 (프로토타입)

바늘이 정중앙에 올 때 뛰어올라, 최고점에서 내려찍어 마을 → 도시 → 나라 → 행성 → 우주를 차례로 부수는 타이밍 게임입니다. 화면은 무한의 계단처럼 세로 화면, 위쪽 시간 막대와 큰 점수, 아래쪽 큰 버튼 하나입니다.

## 규칙

- 주인공은 **땅에서** 출발합니다(건물 왼쪽 옆, 행성·별은 표면 위).
- **점프**: 아래 막대의 바늘이 정중앙에 가까울 때 누를수록 높이 뛰고 피해도 큽니다.
  - PERFECT: 리듬게임처럼 **바늘이 정중앙을 지나는 순간 ±40ms**(바늘이 빨라져도 같은 타이밍, 막대 위 노란 칸은 그만큼 넓어짐), 최고 높이, 피해 ×3 · GREAT(막대 가운데 ±15%) · GOOD(±40%) · MISS(조금만 뜀)
  - 바늘은 처음 초당 0.35번 왕복에서 마지막 스테이지 0.55번까지 아주 조금씩 빨라집니다.
- **내려찍기**: 버튼은 하나이고, 뛰는 순간 노란 [찍기]로 바뀝니다. 최고점에 가까울수록 피해가 큽니다.
  - PERFECT(최고점 ±0.07초) ×2 · GREAT(±0.16초) ×1.5 · GOOD(±0.32초) ×1.15
  - 누르지 않으면 그냥 떨어져 기본 피해만 줍니다.
- 대상을 때리면 **반동으로 살짝 튀어 올라 뒤로 공중제비를 돌고 원래 자리 땅으로** 돌아옵니다.
- 점프하면 **왼쪽 게이지**에 높이가, **빨간 선**에 이번 점프의 최고점이 나옵니다. 최고점 근처에서 선이 깜빡입니다.
- 점프나 내려찍기 중 하나라도 PERFECT면 콤보가 이어져 피해가 10%씩 늘어납니다(최대 +50%).
- 시간 막대가 다 닳기 전에 부숴야 합니다.

## PERFECT 연출 (록리처럼)

- **점프 PERFECT**: 시간이 멈추고 카메라가 주인공에게 확 다가갑니다. 화면이 어두워지고 집중선이 번쩍이며, 주인공이 웅크린 채 금빛 기운에 휩싸이고 땅이 갈라지고 돌멩이가 떠오릅니다("쿠구구구…", 0.85초). 그다음 "콰앙!" 하고 땅이 패이며 폭발하듯 튀어 오릅니다(큰 충격파, 흙먼지, 금빛 꼬리).
- **최고점 PERFECT**: 공중에서 시간이 멈추고 주인공이 빙글빙글 돌며 기운을 빨아들입니다(0.6초). 그다음 "하앗!" 하고 금빛 불꽃을 두르고 내리꽂아 "쾅!!", 금빛 빛줄기와 큰 충격파가 나옵니다.
- 기를 모으는 동안은 시간 막대가 줄지 않습니다.

## 크기: 주인공은 그대로, 세상이 커짐

모든 길이는 실제 m 단위입니다. 주인공은 1.8m 그대로이고, 대상이 커질수록 화면이 넓어져서 주인공이 점점 작아지다 **점**이 됩니다(점이 되면 반짝이는 점과 노란 화살표로 위치 표시). 높이 뛰면 화면이 더 넓어지고, 내려올 때 다시 좁아집니다. 구름(0.6~3km, 8~11km), 새, 성층권의 검은 하늘과 별, 우주의 바위가 실제 높이에 있습니다.

| 지역 | 스테이지 | 대상 (높이·지름) |
|---|---|---|
| 마을 | 1~10 | 나무 오두막 4m … 영주의 성 34m |
| 도시 | 11~20 | 상가 건물 18m … 초고층 빌딩 650m |
| 나라 | 21~30 | 거대 댐 330m … 에베레스트 8,848m |
| 행성 | 31~40 | 포보스 22km … 목성 14만km |
| 우주 | 41~50 | 갈색 왜성 … 블랙홀, 성운, 은하 10만 광년 |

PERFECT 점프 높이는 건물이면 꼭대기 위로 높이의 1.6배 + 6m, 행성·별이면 지름의 2배입니다. 첫 판은 십몇 m, 마지막 판은 수십만 광년.

## 코인과 캐릭터

- 깰 때마다 코인: (10 + 2 × 스테이지 번호) 개, **처음 깨면 두 배**, PERFECT마다 +2.
- [캐릭터] 화면에서 사고 고릅니다.

| 캐릭터 | 값 | 능력 |
|---|---|---|
| 주먹이 | 기본 | 없음 |
| 거북 도사 | 200 | 바늘이 30% 느림 |
| 매눈이 | 400 | 판정 영역(PERFECT·GREAT·GOOD) 1.6배 |
| 시계 소녀 | 400 | 제한 시간 +30% |
| 깡총이 | 800 | 2단 점프: 공중에서 한 번 더 누르면 더 높이 뛰고, 첫 점프 최고점에 맞출수록 피해 ×1.05~×1.6. 세 번째 누름이 찍기 |
| 황금 주먹 | 2,000 | 피해 +25%, 바늘 15% 느림, 판정 영역 1.25배 |

## 밸런스

대상 체력은 스테이지마다 조금씩 늘고(보스 ×1.4), 시간은 16초(보스 22초)에서 조금씩 늘어납니다. 계산으로 확인한 기준(`game.test.js`): 점프 GREAT + 최고점 GREAT를 계속하면 50스테이지 모두 시간 안에 깨고, 대충 누르면 어느 스테이지도 못 깹니다. 조정 값은 `logic.js` 맨 위와 `stageInfo`, `REGIONS`, `CHARACTERS`에 있습니다.

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=3'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 판정, 포물선, 최고점 판정, 피해, 콤보, 스테이지 50개, 캐릭터, 코인, 저장
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 실제 크기 카메라, 기 모으기 연출, 소리, 메뉴, 캐릭터 상점)
```
