# 정중앙 스매시 (프로토타입)

바늘이 정중앙에 올 때 뛰어올라, 최고점에서 내려찍어 마을 → 도시 → 나라 → 행성 → 우주를 차례로 부수는 방치형 타이밍 게임입니다. 화면은 무한의 계단처럼 세로 화면, 위쪽 체력 막대와 큰 남은 체력 숫자, 아래쪽 큰 버튼 하나입니다.

## 규칙 (방치형)

- **시간 제한이 없습니다.** 주인공은 가만히 두어도 **자동으로** 계속 뛰어서 부숩니다(버튼 아래 AUTO 막대가 차면 자동 점프, 찍기 없이 떨어짐).
- **직접 누르면 훨씬 빨라집니다.** 기다리지 않고 바로 뛰고, 정중앙·최고점을 맞혀 자동보다 몇 배 세게 때립니다.
- 주인공은 **땅에서** 출발합니다(건물 왼쪽 옆, 행성·별은 표면 위). 때리면 반동으로 살짝 튀어 올라 뒤로 공중제비를 돌고 원래 자리로 돌아옵니다.
- **점프**: 바늘이 정중앙에 가까울 때 누를수록 높이 뛰고 세게 때립니다.
  - PERFECT: 리듬게임처럼 **바늘이 정중앙을 지나는 순간 ±25ms**(바늘이 빨라져도 같은 타이밍, 막대 위 노란 칸은 그만큼 넓어짐), 최고 높이, 피해 ×3 · GREAT(막대 가운데 ±15%) · GOOD(±40%) · MISS
- **내려찍기**: 버튼은 하나이고 뛰는 순간 [찍기]로 바뀝니다. PERFECT(최고점 ±0.07초) ×2 · GREAT(±0.16초) ×1.5 · GOOD(±0.32초) ×1.15
- 점프나 찍기 중 하나라도 PERFECT면 콤보가 이어져 피해가 10%씩 늘어납니다(최대 +50%).
- 위쪽 막대와 큰 숫자는 **대상의 남은 체력**입니다. 부수면 코인을 받고 잠시 뒤 다음 대상으로 자동으로 넘어갑니다.
- **코인**: 때릴 때마다 (준 피해 / 체력) × 스테이지 코인 × 0.5, 부수면 스테이지 코인을 한 번 더. 스테이지 코인은 20개에서 스테이지마다 ×1.3(보스 ×2).
- **꺼 둔 동안**(최대 8시간)에도 자동 피해로 계속 부수고 코인을 법니다. 돌아오면 "다녀오셨어요!" 창에 결과가 나옵니다.

## 강화 (코인)

| 강화 | 효과 | 값 |
|---|---|---|
| 힘 | 모든 피해 +15%(곱으로 쌓임), 끝없음 | 15 × 1.17^레벨 |
| 자동 점프 속도 | 자동 점프 대기 1.2초에서 -8%씩, 최대 12 | 30 × 1.4^레벨 |
| 자동 조준 | 자동 점프 정확도 55%에서 +3%씩, 최대 10 | 50 × 1.5^레벨 |

게임 중에도 버튼 왼쪽 [강화], 오른쪽 [캐릭터]로 바로 열 수 있습니다(살 수 있는 강화가 있으면 [강화]가 반짝임). 여는 동안에도 자동으로 계속 부숩니다.

## PERFECT 연출 (록리처럼)

- **점프 PERFECT**: 시간이 멈추고 카메라가 주인공에게 확 다가갑니다. 화면이 어두워지고 집중선이 번쩍이며, 주인공이 웅크린 채 금빛 기운에 휩싸이고 땅이 갈라지고 돌멩이가 떠오릅니다("쿠구구구…", 0.85초). 그다음 "콰앙!" 하고 땅이 패이며 폭발하듯 튀어 오릅니다(큰 충격파, 흙먼지, 금빛 꼬리).
- **최고점 PERFECT**: 공중에서 시간이 멈추고 주인공이 빙글빙글 돌며 기운을 빨아들입니다(0.6초). 그다음 "하앗!" 하고 금빛 불꽃을 두르고 내리꽂아 "쾅!!", 금빛 빛줄기와 큰 충격파가 나옵니다.

## 크기: 주인공은 그대로, 세상이 커짐

모든 길이는 실제 m 단위입니다. 주인공은 1.8m 그대로이고, 대상이 커질수록 화면이 넓어져서 주인공이 점점 작아지다 **점**이 됩니다(점이 되면 반짝이는 점과 노란 화살표로 위치 표시). 높이 뛰면 화면이 더 넓어지고, 내려올 때 다시 좁아집니다. 구름(0.6~3km, 8~11km), 새, 성층권의 검은 하늘과 별, 우주의 바위가 실제 높이에 있습니다.

| 지역 | 스테이지 | 대상 (높이·지름) |
|---|---|---|
| 마을 | 1~10 | 나무 오두막 4m … 영주의 성 34m |
| 도시 | 11~20 | 상가 건물 18m … 초고층 빌딩 650m |
| 나라 | 21~30 | 거대 댐 330m … 에베레스트 8,848m |
| 행성 | 31~40 | 포보스 22km … 목성 14만km |
| 우주 | 41~50 | 갈색 왜성 … 블랙홀, 성운, 은하 10만 광년 |

PERFECT 점프 높이는 건물이면 꼭대기 위로 높이의 1.6배 + 6m, 행성·별이면 지름의 2배입니다. 첫 판은 십몇 m, 마지막 판은 수십만 광년.

## 캐릭터

| 캐릭터 | 값 | 능력 |
|---|---|---|
| 주먹이 | 기본 | 없음 |
| 거북 도사 | 300 | 바늘이 30% 느림 |
| 태엽 소녀 | 1,500 | 자동 점프 대기 -40% |
| 매눈이 | 4,000 | 판정 영역(PERFECT·GREAT·GOOD) 1.6배 |
| 깡총이 | 20,000 | 2단 점프: 공중에서 한 번 더 누르면 더 높이 뛰고, 첫 점프 최고점에 맞출수록 피해 ×1.05~×1.6. 세 번째 누름이 찍기 |
| 황금 주먹 | 300,000 | 피해 ×2, 바늘 15% 느림, 판정 영역 1.25배 |

## 밸런스

대상 체력은 3,000에서 스테이지마다 ×1.33(보스 ×2), 코인은 ×1.3. 가장 싼 강화를 계속 사는 가상 플레이어로 맞췄습니다(앱을 켜 둔 채 기준, 꺼 둔 동안의 진행은 빼고).

| | 첫 대상 | 50스테이지 전체 |
|---|---|---|
| 자동만 | 약 2분 | 약 3시간 50분 |
| 직접(평균 GREAT) | 약 30초 | 약 2시간 |

앞쪽은 직접 하면 4배쯤, 뒤쪽은 강화가 쌓여 2배쯤 빠릅니다. 조정 값은 `logic.js`의 `HP_*`, `COIN_*`, `AUTO_*`, `UPGRADES`, `CHARACTERS`에 있습니다.

## 실행

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=4'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 판정, 포물선, 최고점 판정, 피해, 콤보, 스테이지 50개, 방치형(자동 점프, 코인, 강화, 꺼 둔 동안의 진행), 캐릭터, 저장
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 실제 크기 카메라, 기 모으기 연출, 소리, 메뉴, 캐릭터 상점)
```
