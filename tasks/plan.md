# 구현 계획: 스타 스웜 (갤러그 스타일 PWA)

스펙: [../SPEC.md](../SPEC.md)

## 개요

세로 화면 캔버스 슈팅 게임을 순수 JS로 만들고, 홈 화면 웹앱(PWA)으로 포장해 GitHub Pages에 올립니다. 그다음 아이폰에서 홈 화면에 추가해 실행합니다. 게임 로직은 `game.js`에 두고 `node --test`로 검증합니다. 화면, 입력, 루프는 `index.html`이 담당합니다.

## 아키텍처 결정

- **로직과 화면 분리**: `game.js`는 DOM에 접근하지 않는 순수 함수로 작성합니다. 브라우저 없이 테스트할 수 있고, 나중에 Capacitor로 포장할 때도 그대로 씁니다.
- **고정 논리 해상도 360×640**: 모든 계산은 이 좌표로 하고, 그릴 때만 화면 크기에 맞춰 늘립니다. 남는 영역은 검은 여백으로 둡니다. 그래서 기종마다 난이도가 같습니다.
- **`dt` 기반 이동**: 60Hz와 120Hz(ProMotion) 아이폰에서 같은 속도로 움직입니다. 탭 전환 등으로 생기는 큰 `dt`는 0.05초로 자릅니다.
- **단일 상태 객체**: `createState()` → `update(state, dt)` → `render(ctx, state)` 순서로 돕니다. 클래스와 엔진은 쓰지 않습니다.
- **입력**: Pointer Events 하나로 터치와 마우스를 모두 처리합니다. 손가락의 x 좌표를 목표 위치로 삼고, 비행기가 그 위치로 빠르게 따라갑니다.
- **아이콘**: 일회용 스크립트로 PNG를 생성하고, 결과 PNG만 저장소에 둡니다. 생성 스크립트는 저장소에 넣지 않습니다.
- **서비스 워커 캐시 이름에 버전 포함**: 새로 배포하면 이전 캐시를 지워서 업데이트가 반영되게 합니다.

## 의존 관계

```
game.js 상태/플레이어 ─┬─ 발사·편대·충돌 ─┬─ 돌진·적탄·목숨 ── 웨이브·최고점수
index.html 화면/입력 ──┘                    │
                                            └──────────────────── PWA(매니페스트·SW·아이콘) ── GitHub Pages 배포
```

## 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| iOS Safari에서 끌면 페이지가 스크롤되거나 튕기거나 확대됨 | 높음 | `touch-action: none`, `overscroll-behavior: none`, 뷰포트 `user-scalable=no`, pointer 이벤트에서 `preventDefault` |
| iOS 화면 높이 계산 문제(주소창, 노치) | 중간 | `100vh` 대신 `innerHeight`로 맞추고 `resize` 때 다시 계산. `viewport-fit=cover`와 safe-area 여백 적용 |
| 배포 후 아이폰에 예전 버전이 계속 보임 | 중간 | 캐시 이름 버전 올리기. 필요하면 홈 화면 앱을 삭제했다가 다시 추가 |
| `gh` CLI가 로그인되어 있지 않음 | 중간 | 작업 6에서 확인. 로그인이 필요하면 사용자가 직접 `gh auth login` 실행 |
| 오래된 아이폰에서 프레임 저하 | 낮음 | 도형만 그리고, 화면 밖 총알 즉시 제거, 객체 수 상한 유지 |
