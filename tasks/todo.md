공통 검증: `node --test` 통과. 화면 확인은 `python3 -m http.server 8000` → 맥 브라우저에서 모바일 크기(375×812)로 봅니다.

## 작업 1: 화면 뼈대와 플레이어 이동

**설명:** 캔버스가 세로 화면을 꽉 채우고(360×640 비율 유지), 손가락이나 마우스로 끌면 아래쪽 비행기가 좌우로 따라오게 합니다. 게임 루프(`requestAnimationFrame` + `dt`)도 이 작업에서 만듭니다.

**수락 기준:**
- [x] 모바일 크기 화면에서 캔버스가 비율을 유지하며 최대 크기로 표시되고, 스크롤과 확대가 일어나지 않는다
- [x] 끌면 비행기가 손가락 x 위치를 따라가고, 화면 양 끝을 벗어나지 않는다
- [x] 테스트: 목표 위치로 이동, 양 끝 경계에서 멈춤

**검증:** `node --test`, 브라우저 모바일 화면에서 끌기 확인
**의존:** 없음
**파일:** `index.html`, `game.js`, `game.test.js`
**규모:** 중간

## 작업 2: 자동 발사, 적 편대, 격추와 점수

**설명:** 비행기가 일정 간격으로 총알을 쏘고, 위쪽에 적 편대(예: 4줄 × 8마리)가 좌우로 오가게 합니다. 총알이 적에 맞으면 둘 다 사라지고 점수가 오릅니다.

**수락 기준:**
- [x] 총알이 일정 간격으로 나가고, 화면 밖으로 나가면 제거된다
- [x] 편대가 좌우로 움직이다가 끝에 닿으면 방향을 바꾼다
- [x] 테스트: `hits` 충돌 판정, 격추 시 적과 총알 제거 및 점수 증가

**검증:** `node --test`, 브라우저에서 적을 맞혀 점수가 오르는지 확인
**의존:** 작업 1
**파일:** `index.html`, `game.js`, `game.test.js`
**규모:** 작은~중간

## 작업 3: 적 돌진, 적 총알, 목숨, 게임 오버와 재시작

**설명:** 주기적으로 적 한 마리가 곡선을 그리며 플레이어 쪽으로 돌진하고, 적이 총을 쏘게 합니다. 적 총알이나 적 본체에 맞으면 목숨이 줄고, 잠깐 무적 시간이 생깁니다. 목숨이 0이 되면 게임 오버 화면이 뜨고, 탭하면 재시작합니다.

**수락 기준:**
- [x] 돌진한 적이 화면 아래로 빠지면 편대 자리로 돌아온다
- [x] 피격 시 목숨 -1과 짧은 무적. 0이 되면 게임 오버 → 탭하면 새 게임
- [x] 테스트: 피격 시 목숨 감소, 무적 중 피격 무시, 목숨 0이면 게임 오버, 재시작 시 상태 초기화

**검증:** `node --test`, 브라우저에서 일부러 맞아서 게임 오버 → 재시작 확인
**의존:** 작업 2
**파일:** `index.html`, `game.js`, `game.test.js`
**규모:** 중간

## 작업 4: 스테이지, 메뉴 화면, 진행 저장 (요청으로 범위 변경)

**설명:** 무한 웨이브 대신 5개 스테이지를 만듭니다. 메인 화면 → 스테이지 선택 → 플레이 흐름, 일시정지 메뉴, STAGE CLEAR와 GAME OVER 화면을 추가합니다. 클리어 기록은 `localStorage`에 저장합니다.

**수락 기준:**
- [x] 메인 → 스테이지 선택 → 플레이. 잠긴 스테이지는 누를 수 없고, 클리어한 스테이지에는 CLEAR와 최고 점수가 표시되며 다시 들어갈 수 있다
- [x] 일시정지 메뉴: 계속하기, 다시 시작, 스테이지 선택. 앱이 백그라운드로 가면 자동 일시정지
- [x] STAGE CLEAR: 다음 스테이지, 스테이지 선택 / GAME OVER: 다시 시작, 스테이지 선택
- [x] 테스트: 스테이지가 올라갈수록 빨라짐, 전멸 시 클리어, 클리어 기록과 잠금 해제 규칙

**검증:** `node --test`, 브라우저에서 메뉴 흐름 전체 클릭, 새로고침 후 CLEAR 유지
**의존:** 작업 3
**파일:** `index.html`, `game.js`, `game.test.js`
**규모:** 중간
