# 스윙 시티

거미줄로 빌딩 사이를 그네 타듯 날아다니며 빛나는 조각 60개를 모으는 로우폴리 3D 자유 비행 게임(three.js). 거미줄 액션에서 영감을 받은 오리지널 히어로예요(원작 이름·슈트는 쓰지 않음).

## 하는 법
- 왼쪽 아래를 끌어 방향, 화면을 끌어 시점.
- 🕸️ 스윙을 누르고 있으면 앞쪽 위 옥상 모서리에 줄이 붙고, 줄 길이만큼 진자처럼 흔들려요. 떼면 그 기세로 날아가요(올라가는 중에 떼면 조금 더 뜸). 다시 누르면 다음 줄.
- 흔들리는 동안 앞으로 밀면 힘이 실려 빨라져요. 줄은 조금씩 감겨 높이를 유지해요.
- 🎯 당기기: 앞 빌딩 꼭대기로 곧장 날아가요.
- ⤴ 점프. 벽 쪽으로 밀면 벽을 달려 올라가 옥상으로.
- 더 높은 빌딩이 없으면 근처에 빌딩이 있을 때 앞쪽 위 허공에 줄을 걸어요.
- 빠를수록 시야가 넓어지고 바람 소리가 커져요.
- 컴퓨터: WASD, J 스윙(누르고 있기), K 당기기, 스페이스 점프.

## 물리
줄은 늘어나지 않는 끈: 줄보다 멀어지면 구 위로 되돌리고 바깥으로 가는 속도를 없애요. 중력 26m/s², 최고 속도 62m/s, 빠를 땐 한 프레임을 잘게 나눠 벽을 뚫지 않게.

## 파일
```
logic.js      → 줄 붙일 곳 고르기, 줄·스윙 물리, 도시 배치, 조각 배치, 저장
index.html    → 로우폴리 도시, 주인공(Blender 모델), 줄, 카메라, 조작, 소리
models/person.glb → 주인공 모델(../sniper3d/tools/build_models.py)
vendor/       → three.js 0.170 (MIT)
game.test.js  → node --test
```
