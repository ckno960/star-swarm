# 나이트 라인 (프로토타입)

기사가 4방향 중 하나로 일직선으로 달려가, 그 방향에서 처음 만나는 몬스터를 처치하고 그 자리에 섭니다. 한붓 그리기처럼 순서를 잘 골라 몬스터를 모두 처치하면 클리어입니다.

## 규칙

- 몬스터가 없는 방향으로는 움직일 수 없습니다.
- **11스테이지부터 갑옷 오크**가 나옵니다. 두 번 때려야 쓰러집니다. 첫 번째 공격에는 버티고, 기사는 달려온 방향에서 오크 바로 앞 칸에 멈춥니다(이미 바로 옆이면 제자리에서 때립니다). 머리 위 빨간 칸이 남은 체력입니다. 뒤로 갈수록 갑옷 오크 수가 늘어납니다.
- 몬스터가 남았는데 어느 방향에도 몬스터가 없으면 막힙니다. [되돌리기]나 [다시]로 풀면 됩니다.
- [힌트]는 지금 상태에서 깨는 다음 방향을 보여 줍니다. 이미 못 깨는 상태면 그렇다고 알려 줍니다.
- 스테이지는 끝이 없고, 뒤로 갈수록 판이 커지고(5×5 → 10×10) 몬스터가 늘어납니다. 같은 스테이지는 누가 해도 같은 판입니다.
- 클리어한 스테이지는 기기에 저장되고, 위쪽 ◀ ▶로 다시 할 수 있습니다.

## 보너스 파친코 (10스테이지마다)

10, 20, 30… 스테이지를 처음 깨면 보너스 파친코가 나옵니다. 같은 스테이지를 다시 깨도 두 번 나오지는 않습니다.

- 공 10개를 판 위쪽에서 떨어뜨립니다. 누른 자리에서 떨어지고, [공 발사]는 가운데 근처로 떨어뜨립니다.
- 바닥 칸: 0 / 5 / 10 / **START** / 10 / 5 / 0 코인
- START에 들어가면 슬롯 3개가 돕니다. 돌고 있을 때 들어간 START는 최대 4개까지 대기합니다. 앞 두 개가 같으면 '리치' 연출이 붙습니다.

| 슬롯 | 보상 |
|---|---|
| 7 7 7 | **JACKPOT** 300 코인 + 보너스 공 5개 |
| 같은 그림 3개 | 100 코인 + 보너스 공 2개 |
| 같은 그림 2개 | 20 코인 |
| 그 외 | 꽝 |

코인은 기기에 저장되고 화면 오른쪽 위에 보입니다. 가상 코인이며 현금 결제나 환전은 없습니다.

## 조작

- 휴대폰: 판 위를 손가락으로 밀기, 또는 방향 버튼
- PC: 방향키/WASD, Z 되돌리기, R 다시

## 실행

서버가 필요 없는 정적 페이지입니다.

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

## 판 만드는 방법

정답 경로를 먼저 만들고 그 경로 위에 몬스터를 놓아서, 항상 깰 수 있는 판만 나오게 합니다. 기사가 한 번 지나간 길에는 나중 몬스터를 두지 않습니다. 그래서 정답 경로의 다음 몬스터가 언제나 그 방향의 첫 몬스터가 됩니다.

갑옷 오크는 경로에 놓는 순간 한 대 맞은 것으로 치고, 두 번째 공격을 받을 때까지는 길을 막는 벽으로 다룹니다. 생성기는 만든 정답 경로도 같이 저장하므로, 플레이어가 그 경로를 따라가는 동안에는 힌트가 즉시 나옵니다.

## 구조

```
game.js          → 순수 로직 (판 생성, 이동, 갑옷 오크, 되돌리기, 막힘 판정, 풀이, 힌트)
pachinko.js      → 보너스 파친코 로직 (공 물리, 바닥 칸, 슬롯 상금)
game.test.js, pachinko.test.js
index.html       → 픽셀 렌더링, 애니메이션, 입력, 파친코 화면, 스테이지·코인 저장
```
