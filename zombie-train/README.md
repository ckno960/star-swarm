# 좀비 열차

좀비로 가득한 세상을 달리는 열차 객실에서 보라 고양이 **모모**를 지키는 생존 관리 게임. 고밀도 픽셀 아트.

## 하는 법
- **수치 4개**: 🍖 배부름 · 🔥 체온 · ❤️ 체력 · 😺 기분. 배부름이 0이거나 체온이 20 아래면 체력이 줄어요.
- **먹이 주기**(통조림 1개, 배부름 +30), **난로 켜기/끄기**(연료를 씀), **창문 수리**(고철 2), **약 먹이기**(체력 +40).
- **연료**: 열차(시간당 0.5)와 난로가 같이 써요. 바닥나면 열차가 멈추고 좀비가 더 몰려와요. 이때는 **땔감 구하기**(2시간, 위험).
- **좀비**: 창문에 붙으면 **눌러서 때리세요**. 내버려 두면 창문이 깨지고, 그다음엔 모모가 다쳐요. 밤에 많고, 4일마다 **좀비 떼의 밤**이 와요.
- **역**: 50km마다 정차. 빠르게 둘러보기(1시간, 위험 낮음), 꼼꼼히 수색하기(3시간, 물자 2배 이상, 위험 높음), 그냥 출발 중에서 골라요. 역마다 편의점·연료 창고·정비소·약국·빈 역이 있어요(라디오가 있으면 미리 알려 줘요).
- **개조**(고철): 무기, 창문 철판, 전기 철조망, 난로, 담요, 텃밭, 엔진, 라디오, 자동 급식기, 구급상자.
- **노선**: 서울 → 대전 → 대구 → 부산 → … 갈수록 길고 위험해요. 쓰러지면 개조는 남기고 같은 노선을 처음부터 다시.
- 현실 1초 = 게임 5분(하루 약 4.8분). 앱을 닫으면 열차는 터널에서 기다려요(오프라인 진행 없음).

## 그래픽
가로 180픽셀 버퍼에 픽셀을 직접 찍고(안티에일리어싱 없음) 화면 크기로 키워요.
- 방은 원근 투영으로 짓고, 벽·바닥·천장은 픽셀마다 광선을 역산해 나뭇결·얼룩·러그 무늬를 입혀요.
- 조명은 주변광 + 스탠드 + 난로 불 + 창빛을 더한 뒤 단계로 끊고 바이어 디더링.
- 창밖은 시간(낮·노을·밤), 비, 무너진 도시, 전봇대, 어슬렁거리는 좀비가 열차 속도로 흘러가요.

## 파일
```
logic.js      → 생존 수치, 연료·속도, 좀비, 역 수색, 개조, 노선, 저장 (화면과 분리)
pixel.js      → 픽셀 버퍼, 방 짓기, 고양이·좀비 스프라이트, 창밖, 조명
index.html    → 화면, 패널, 버튼, 모달, 소리, 루프
game.test.js  → node --test
```
