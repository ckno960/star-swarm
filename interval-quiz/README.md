# 음정 퀴즈

높은음자리표 오선지에 두 음을 보여주고, 그 사이 음정을 **성질**(완전·장·단·증·감·겹증·겹감)과 **도수**(1~8도)로 따로 골라 맞히는 휴대폰용 퀴즈입니다.

## 규칙

- 성질과 도수를 하나씩 고르고 [확인]을 누릅니다. 맞히면 초록, 틀리면 빨간색으로 표시되고 정답 버튼이 초록으로 보입니다.
- 풀이가 함께 나옵니다. 예: `레 → 파♯ · 3도, 반음 4개 → 장3도`
- 단계마다 10문제이고, **8개 이상** 맞히면 다음 단계가 열립니다. 단계별 최고 점수와 CLEAR가 기기에 저장됩니다.
- 틀린 문제는 **오답 노트**에 모입니다(최대 100개). [틀린 문제 다시 풀기]에서 맞히면 노트에서 빠집니다.

## 단계

| 단계 | 내용 | 임시표 |
|---|---|---|
| 1. 흰건반 | 도레미파솔라시끼리. 미–파·시–도 반음, 파–시 증4도 | 없음 |
| 2. ♯·♭ 하나 | 완전·장·단, 증4도·감5도 | ♯·♭ |
| 3. 증·감 | 모든 도수의 증·감음정 위주 | ♯·♭ |
| 4. 겹증·겹감 | 겹증·겹감음정 위주 | ♯·♭·𝄪·𝄫 |
| 5. 종합 | 모든 음정, 절반은 내려가는 음정 | ♯·♭·𝄪·𝄫 |

음은 가운데 도(덧줄 1개)부터 높은 도(덧줄 2개)까지 나옵니다. 감1도는 위 음이 아래로 내려가 버려서 내지 않습니다.

## 실행

```
python3 -m http.server 8000   # 저장소 최상위에서 실행 → http://localhost:8000/interval-quiz/
node --test                   # 이 폴더에서 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=1'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 음·음정 계산, 단계별 문제 만들기, 채점, 풀이, 진행·오답 노트
game.test.js   → 로직 테스트
index.html     → 화면 전체 (오선지·음자리표·임시표 SVG 그리기, 버튼, 결과, 오답 노트)
```
