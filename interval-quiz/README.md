# 음악 이론 퀴즈

휴대폰용 음악 이론 퀴즈입니다. 처음 화면에서 문제 유형 4가지 중 하나를 고르고, 유형마다 **단계별 연습 · 자유연습 · 오답 노트**가 있습니다. 진행과 오답 노트는 유형마다 따로 저장되고, 건반·듣기 버튼·피아노 소리는 같이 씁니다.

| 유형 | 문제 | 답 |
|---|---|---|
| 음정 퀴즈 | 오선지의 두 음 | 성질(완전·장·단·증·감·겹증·겹감) + 도수(1~8도) |
| 코드 퀴즈 | 오선지의 화음 | 영문 코드 이름 보기 4개 |
| 조표 퀴즈 | 오선지의 ♯·♭ 조표 + "장조는?" 또는 "단조는?" | 영문 조 이름 보기 4개 (예: D major) |
| 코드톤 퀴즈 | 코드 이름 (예: Cm7) | 비기너: 구성음 보기 4개 / 프로: 음 이름 직접 입력 |

## 음정 퀴즈

- **단계별 연습**: 아래 5단계를 차례로 엽니다.
- **자유연습**: 성질(완전·장·단·증·감·겹증·겹감 중 여러 개), 문제 수(5·10·20·30·50), 방향(올라가는 음정만 / 내려가는 음정도)을 골라 풉니다. 고른 성질이 고르게 나오고, 임시표는 𝄪·𝄫까지 붙습니다. 설정은 기기에 저장됩니다.
- **오답 노트**: 두 연습에서 틀린 문제가 모입니다.
- 풀이 예: `레 → 파♯ · 3도, 반음 4개 → 장3도`

### 음정 단계

| 단계 | 내용 | 임시표 |
|---|---|---|
| 1. 흰건반 | 도레미파솔라시끼리. 미–파·시–도 반음, 파–시 증4도 | 없음 |
| 2. ♯·♭ 하나 | 완전·장·단, 증4도·감5도 | ♯·♭ |
| 3. 증·감 | 모든 도수의 증·감음정 위주 | ♯·♭ |
| 4. 겹증·겹감 | 겹증·겹감음정 위주 | ♯·♭·𝄪·𝄫 |
| 5. 종합 | 모든 음정, 절반은 내려가는 음정 | ♯·♭·𝄪·𝄫 |

음은 가운데 도(덧줄 1개)부터 높은 도(덧줄 2개)까지, 건반으로 칠 수 있는 음만 나옵니다(도♭4처럼 건반 밖으로 나가는 음은 내지 않음). 감1도는 위 음이 아래로 내려가 버려서 내지 않습니다.

## 공통 규칙

- 답을 고르고 [확인]을 누릅니다. 맞히면 초록, 틀리면 빨간색으로 표시되고 정답이 초록으로 보이며, 풀이가 함께 나옵니다.
- 단계별 연습은 단계마다 10문제이고, **8개 이상** 맞히면 다음 단계가 열립니다. 단계별 최고 점수와 CLEAR가 기기에 저장됩니다.
- 틀린 문제는 **오답 노트**에 모입니다(최대 100개). [틀린 문제 다시 풀기]에서 맞히면 노트에서 빠집니다.

## 코드 퀴즈

오선지에 화음을 세로로 쌓아 보여주고, 보기 4개 중 맞는 **영문 코드 이름**을 고릅니다. 자리바꿈은 `C/E`처럼 슬래시로 씁니다.

| 단계 | 코드 |
|---|---|
| 1. 장·단 3화음 | C, Cm |
| 2. 증·감 3화음 | + Caug, Cdim |
| 3. 3화음 자리바꿈 | 위 4종의 첫째·둘째 자리바꿈 |
| 4. 7화음 | CM7, C7, Cm7, Cm7♭5, Cdim7, CmM7 |
| 5. 7화음 자리바꿈 | 7화음의 첫째·둘째·셋째 자리바꿈 |
| 6. sus·add·6 | Csus2, Csus4, C7sus4, C6, Cm6, Cadd9 |
| 7. 종합 | 전부, 자리바꿈도 |

- 보기는 정답과 헷갈리기 쉬운 코드로 만듭니다: 같은 근음의 다른 종류, 같은 종류의 다른 근음(화음 안의 다른 음이나 반음 차이), 다른 자리바꿈. 정답과 **소리가 같은 코드**(예: C6과 Am7/C, Caug와 Eaug/C)는 보기에 넣지 않습니다.
- sus·add·6화음은 자리바꿈하면 다른 코드와 이름이 겹쳐서 기본형으로만 냅니다.
- 근음으로 C♭·F♭·E♯·B♯은 쓰지 않습니다. 코드 이름의 겹올림·겹내림은 폰 글꼴에서 깨지지 않게 `♯♯`·`♭♭`로 씁니다(악보 위 기호는 그림이라 𝄪·𝄫).
- 악보에서 2도로 붙은 음은 오른쪽으로 비켜 쓰고, 임시표는 겹치지 않게 왼쪽으로 줄을 나눠 답니다.
- 풀이 예: `E–G–C · 근음 C, 장3화음, 첫째 자리바꿈 → C/E`
- 자유연습: 코드 종류 16가지 중 여러 개, 자리바꿈(기본형만 / 자리바꿈도), 문제 수(5·10·20·30·50).
- 건반에는 화음의 모든 음이 노랑으로 표시되고, 이름표가 붙으면 두 줄로 엇갈려 답니다. [같이 듣기]는 화음 전체를, [따로 듣기]는 아래 음부터 차례로 들려줍니다.

## 조표 퀴즈

- 높은음자리표에 조표(♯ 파·도·솔·레·라·미·시, ♭ 시·미·라·레·솔·도·파 순서)를 보여주고, 문제마다 장조 또는 단조를 묻습니다.
- 보기는 같은 장조·단조끼리: 조표가 하나 많거나 적은 조, 같은 개수의 반대 조표(♯2 ↔ ♭2), 소리가 같은 딴이름 조(B major ↔ C♭ major).
- 풀이 예: `♯ 2개 (F♯ C♯) → D major의 나란한단조 → B minor`

| 단계 | 내용 |
|---|---|
| 1. ♯ 장조 | 조표 없음 ~ ♯ 4개 |
| 2. ♭ 장조 | ♭ 1 ~ 4개 |
| 3. 모든 장조 | ♯·♭ 7개까지 15개 |
| 4. 단조 | ♯·♭ 4개까지 |
| 5. 모든 단조 | ♯·♭ 7개까지 15개 |
| 6. 종합 | 장조·단조 섞어서 |

- 자유연습: 장조·단조(여러 개), ♯조·♭조(여러 개, 조표 없음은 둘 다에 들어감), 문제 수.
- 소리가 곧 답이라, 채점한 뒤에만 [같이 듣기](으뜸화음)·[따로 듣기](스케일, 단조는 자연단음계)가 켜지고 건반에 스케일이 표시됩니다. 채점 전 건반에는 조표의 ♯·♭ 음만 표시됩니다.

## 코드톤 퀴즈

- 들어갈 때 **비기너**(구성음 묶음 보기 4개)와 **프로**(음 이름 직접 입력)를 고릅니다. 두 방식은 진행과 오답 노트를 따로 저장하고, 자유연습 설정은 같이 씁니다.
- 프로 입력: 임시표(♭♭ ♭ ♮ ♯ ♯♯)를 먼저 누르고 음 이름(C~B)을 누르면 한 음이 들어갑니다(임시표는 그 음 하나에만 붙음). ⌫로 한 음 지우기. 순서는 상관없고, **E♭과 D♯처럼 철자까지** 맞아야 정답입니다.
- 비기너 보기: 같은 근음의 다른 종류(음 개수가 같은 것), 한 음을 딴이름으로 쓴 것(E♭ ↔ D♯), 한 음을 반음 바꾼 것.
- 풀이 예: `Cm7 = C–E♭–G–B♭ · 근음 C, 단7화음 (단3도 + 완전5도 + 단7도)`

| 단계 | 코드 |
|---|---|
| 1. 장·단 3화음 | C, Cm |
| 2. 증·감 3화음 | + Caug, Cdim |
| 3. 7화음 기본 | CM7, C7, Cm7 |
| 4. 모든 7화음 | + Cm7♭5, Cdim7, CmM7 |
| 5. sus·add·6 | Csus2, Csus4, C7sus4, C6, Cm6, Cadd9 |
| 6. 종합 | 전부 |

- 자유연습: 코드 종류 16가지(여러 개), 문제 수.
- 채점 전에는 코드 이름만 크게 보여주고, 채점한 뒤에 악보·건반에 구성음을 보여주고 소리를 들려줍니다.

## 소리와 건반

- 문제 화면 아래에 **2옥타브 건반**(가운데 도 ~ 높은 도, 25건반)이 있습니다. 음정 퀴즈는 두 음이 건반에 색으로 표시되고(악보 왼쪽 음은 노랑, 오른쪽 음은 파랑), 건반 위에 음 이름이 붙습니다. 같은 건반이면(예: 도♯·레♭) 반반 색으로 표시합니다.
- [같이 듣기]: 두 음을 동시에, [따로 듣기]: 악보 왼쪽 음부터 하나씩 들려줍니다. 건반을 눌러도 그 음이 납니다.
- [건반 숨기기]/[건반 보이기]로 건반과 표시를 끄고 켭니다. 듣기 버튼은 그대로 남고, 설정은 기기에 저장됩니다.
- 소리는 그랜드 피아노 녹음 [Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3) (Alexander Holm, CC BY 3.0)입니다. `piano/`에 단3도 간격으로 9개(도4·레♯4·파♯4·라4·도5·레♯5·파♯5·라5·도6)를 넣고, 나머지 음은 가장 가까운 녹음의 재생 속도를 바꿔 냅니다. 녹음을 못 불러오면 직접 만든 소리로 대신 냅니다. 아이폰은 무음 모드에서 소리가 나지 않을 수 있습니다.

## 실행

```
python3 -m http.server 8000   # 저장소 최상위에서 실행 → http://localhost:8000/interval-quiz/
node --test                   # 이 폴더에서 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=5'`처럼 바뀐 파일의 `?v=` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 음·음정 계산, 단계별·자유연습 문제 만들기, 채점, 풀이, 진행·오답 노트
game.test.js   → 음정 로직 테스트
chords.js      → 화음 쌓기, 코드 이름, 코드 단계·자유연습 문제와 보기, 코드 오답 노트
chords.test.js → 코드 로직 테스트
keys.js        → 조표 그리기 자리, 장조·단조 이름, 스케일, 조표 단계·자유연습 문제와 보기
tones.js       → 코드톤 단계·자유연습 문제, 비기너 보기, 프로 채점
keys.test.js   → 조표·코드톤 로직 테스트
piano/         → 그랜드 피아노 녹음 9개 (mp3)
index.html     → 화면 전체 (오선지·음자리표·임시표 SVG 그리기, 버튼, 소리, 건반, 결과, 오답 노트)
```
