# 음정 퀴즈

높은음자리표 오선지에 두 음을 보여주고, 그 사이 음정을 **성질**(완전·장·단·증·감·겹증·겹감)과 **도수**(1~8도)로 따로 골라 맞히는 휴대폰용 퀴즈입니다.

## 메뉴

- **단계별 연습**: 아래 5단계를 차례로 엽니다.
- **자유연습**: 성질(완전·장·단·증·감·겹증·겹감 중 여러 개), 문제 수(5·10·20·30·50), 방향(올라가는 음정만 / 내려가는 음정도)을 골라 풉니다. 고른 성질이 고르게 나오고, 임시표는 𝄪·𝄫까지 붙습니다. 설정은 기기에 저장됩니다.
- **오답 노트**: 두 연습에서 틀린 문제가 모입니다.

## 규칙

- 성질과 도수를 하나씩 고르고 [확인]을 누릅니다. 맞히면 초록, 틀리면 빨간색으로 표시되고 정답 버튼이 초록으로 보입니다.
- 풀이가 함께 나옵니다. 예: `레 → 파♯ · 3도, 반음 4개 → 장3도`
- 단계별 연습은 단계마다 10문제이고, **8개 이상** 맞히면 다음 단계가 열립니다. 단계별 최고 점수와 CLEAR가 기기에 저장됩니다.
- 틀린 문제는 **오답 노트**에 모입니다(최대 100개). [틀린 문제 다시 풀기]에서 맞히면 노트에서 빠집니다.

## 소리와 건반

- 문제 화면 아래에 **2옥타브 건반**(가운데 도 ~ 높은 도, 25건반)이 있습니다. 문제의 두 음이 건반에 색으로 표시되고(악보 왼쪽 음은 노랑, 오른쪽 음은 파랑), 건반 위에 음 이름이 붙습니다. 같은 건반이면(예: 도♯·레♭) 반반 색으로 표시합니다.
- [같이 듣기]: 두 음을 동시에, [따로 듣기]: 악보 왼쪽 음부터 하나씩 들려줍니다. 건반을 눌러도 그 음이 납니다.
- [건반 숨기기]/[건반 보이기]로 건반과 표시를 끄고 켭니다. 듣기 버튼은 그대로 남고, 설정은 기기에 저장됩니다.
- 소리는 그랜드 피아노 녹음 [Salamander Grand Piano](https://archive.org/details/SalamanderGrandPianoV3) (Alexander Holm, CC BY 3.0)입니다. `piano/`에 단3도 간격으로 9개(도4·레♯4·파♯4·라4·도5·레♯5·파♯5·라5·도6)를 넣고, 나머지 음은 가장 가까운 녹음의 재생 속도를 바꿔 냅니다. 녹음을 못 불러오면 직접 만든 소리로 대신 냅니다. 아이폰은 무음 모드에서 소리가 나지 않을 수 있습니다.

## 단계

| 단계 | 내용 | 임시표 |
|---|---|---|
| 1. 흰건반 | 도레미파솔라시끼리. 미–파·시–도 반음, 파–시 증4도 | 없음 |
| 2. ♯·♭ 하나 | 완전·장·단, 증4도·감5도 | ♯·♭ |
| 3. 증·감 | 모든 도수의 증·감음정 위주 | ♯·♭ |
| 4. 겹증·겹감 | 겹증·겹감음정 위주 | ♯·♭·𝄪·𝄫 |
| 5. 종합 | 모든 음정, 절반은 내려가는 음정 | ♯·♭·𝄪·𝄫 |

음은 가운데 도(덧줄 1개)부터 높은 도(덧줄 2개)까지, 건반으로 칠 수 있는 음만 나옵니다(도♭4처럼 건반 밖으로 나가는 음은 내지 않음). 감1도는 위 음이 아래로 내려가 버려서 내지 않습니다.

## 실행

```
python3 -m http.server 8000   # 저장소 최상위에서 실행 → http://localhost:8000/interval-quiz/
node --test                   # 이 폴더에서 로직 테스트
```

배포할 때는 `index.html`의 `import ... './logic.js?v=3'` 숫자를 올립니다(캐시 때문).

## 구조

```
logic.js       → 음·음정 계산, 단계별·자유연습 문제 만들기, 채점, 풀이, 진행·오답 노트
game.test.js   → 로직 테스트
piano/         → 그랜드 피아노 녹음 9개 (mp3)
index.html     → 화면 전체 (오선지·음자리표·임시표 SVG 그리기, 버튼, 소리, 건반, 결과, 오답 노트)
```
