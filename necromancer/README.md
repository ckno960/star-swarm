# 멸망의 네크로맨서 (프로토타입)

네크로맨서가 되어 마을 → 도시 → 나라 → 행성 → 우주를 차례로 멸망시키는 자동 전투 게임입니다. 쓰러뜨린 몬스터를 길들여 소환수 군단을 키웁니다.

## 규칙

- 지역 5개, 지역마다 스테이지 10개(10번째는 보스). 보스를 쓰러뜨리면 룰렛을 돌리고 다음 지역이 열립니다.
- **처음엔 슬라임 1마리**로 시작합니다. **군단은 길들인 숫자만큼만** 소환됩니다(길들인 소환수는 모두 전투에 나감).
- **전투 구도**: 길이 왼쪽 아래(적 출발점)에서 오른쪽 위(네크로맨서)로 대각선으로 납니다.
  - 적은 차례로 몰려나와 **네크로맨서를 노리고** 진군합니다.
  - 소환수는 네크로맨서 앞을 지키다가 자기 줄로 오는 적을 맞으러 나가고, **마주친 적과 싸웁니다**.
  - 길은 6줄로 나뉘고, 줄마다 한 번에 맞붙을 수 있는 폭이 있어서 뒷줄은 앞줄이 쓰러지면 앞으로 나옵니다.
  - 어떤 줄에 소환수가 없으면 그 줄의 적은 그대로 네크로맨서까지 가서 때립니다(한가한 줄의 소환수가 옮겨 가 막음).
  - 네크로맨서가 쓰러지면 패배(3분이 지나도 패배), 적을 모두 쓰러뜨리면 승리.
- 네크로맨서 스킬(직접 누르거나 [자동 스킬]로 맡김)
  - **영혼 폭발**: 나와 있는 모든 적에게 네크로맨서 공격력 ×3 피해, 쿨타임 12초
  - **되살리기**: 쓰러진 소환수를 체력 50%로 부활(군단의 10%, 최소 3마리), 쿨타임 25초
- 이기면 "파괴!" 연출 뒤 **보상(영혼)** 과 **길들이기!**
  - 영혼: 스테이지마다 정해진 양, 처음 깨면 두 배. 져도 쓰러뜨린 적 비율만큼 조금(최대 절반) 받습니다.
  - 길들이기: **이번 전투에서 만난 적 종류 중** 최대 3가지 가운데 하나를 골라 시도합니다. 성공하면 **그 전투에서 쓰러뜨린 같은 종류의 35%(최소 2마리)** 가 한꺼번에 합류합니다. 보스는 한 마리이고, 이미 가졌으면 대신 레벨 +2.
  - 결과가 나오면 "이 스테이지를 다시 할까요?" 와 함께 [다시 하기] [다음 스테이지] [지도로]를 고릅니다.
- **소환수 키우기**: 영혼으로 종류별 레벨을 올립니다(같은 종류는 모두 같은 레벨, 최대 30, 레벨당 능력치 +12%). 비용 = 3 × 별 × 1.3^(레벨-1) × (진화 단계+1).
- **진화**: 레벨 10부터 할 수 있습니다. 진화하면 이름 앞에 상급 → 고대가 붙고, 기본 능력치가 2.2배가 되며 레벨은 1부터 다시 시작합니다(최대 2단계). 비용 = 100 × 별 × (진화 단계+1). 보스는 진화하지 않습니다.
- **보스 룰렛**: 보스를 깰 때마다 돌립니다. 영혼 ×2 / 영혼 ×5 / 군단 증원(가장 많은 종류 +30%) / 레벨 +3(무작위 종류) / 무료 진화 / 잭팟 영혼 ×15.

| 등급 | 몸 모양 · 특성 | 길들이기 확률 |
|---|---|---|
| ★ | 점액형 · 재생 (계속 조금씩 회복) | 70% |
| ★★ | 짐승형 · 속공 (공격과 이동이 빠름) | 55% |
| ★★★ | 비행형 · 급습 (앞줄을 뛰어넘어 뒤쪽 적까지 공격) | 40% |
| ★★★★ | 인간형 · 흡혈 (준 피해 30% 회복) | 25% |
| ★★★★★ | 골렘형 · 광역 (맞은 적 뒤 2마리에게도 30% 피해) | 12% |
| 👑 보스 | 광역 | 8% |

- 적의 수는 스테이지마다 16%씩 늘어납니다: 1스테이지 2마리 → 마을 보스 약 9 → 도시 약 35 → 나라 약 150 → 행성 약 650 → 우주 보스 약 2,900마리. 약한 몬스터가 떼로, 강한 몬스터는 드물게 나옵니다. 행성·우주는 적 레벨이 조금 더 높습니다.
- 네크로맨서도 처음 깬 스테이지 수만큼 강해집니다(레벨 = 깬 스테이지 + 1).

## 지역과 몬스터

| 지역 | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ | 보스 |
|---|---|---|---|---|---|---|
| 마을 | 슬라임 | 들개 | 까마귀 | 마을 경비병 | 허수아비 골렘 | 촌장 오우거 |
| 도시 | 하수구 슬라임 | 도둑고양이 | 네온 박쥐 | 도시 경찰 | 강철 골렘 | 기계 시장 |
| 나라 | 독 슬라임 | 군마 | 그리폰 | 왕국 기사 | 공성 골렘 | 폭군 국왕 |
| 행성 | 산성 점액 | 모래 도마뱀 | 익룡 | 행성 수호자 | 용암 거인 | 대지룡 |
| 우주 | 암흑 물질 | 별사냥개 | 혜성 정령 | 타락 천사 | 성운 거인 | 창조신 |

## 화면

메인(⚙ 환경설정) → 모험(멸망 지도) → 전투 준비(적 종류별 수, 내 군단, 소환수 키우기) → 전투(❚❚ 일시정지, 속도 ×1/×2/×3, 자동 스킬, 남은 아군·적 수, 네크로맨서 체력) → 파괴 → 보상과 길들이기 → (보스면 룰렛) → 다시 하기 / 다음 스테이지. 우주 보스까지 깨면 엔딩.

[소환수] 화면: 영혼, 종류별 레벨·마리 수, [레벨 업] [진화] 버튼, 이름을 누르면 한 마리 능력치.

PC 단축키: Esc 일시정지, Q/1 영혼 폭발, W/2 되살리기.

## 실행

서버가 필요 없는 정적 페이지입니다.

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

**배포할 때**: `index.html`의 import 주소 끝 `?v=` 숫자를 하나 올립니다(세 군데, 지금 v=3). GitHub Pages 캐시 때문에 새 화면이 예전 파일을 받아 멈추는 것을 막습니다.

## 밸런스

가상 플레이어로 처음부터 끝까지 여러 번 진행해 보며 맞췄습니다. 가상 플레이어는 이기면 기대값이 큰 후보를 길들이고, 영혼은 진화 → 효율 좋은 레벨 업 순으로 쓰고, 지면 이길 수 있는 앞 스테이지로 물러나 키운 뒤 다시 도전합니다.

| | 결과 (6번 진행) |
|---|---|
| 전체 전투 수 | 113~168번 (평균 20초, ×1 기준 약 40~55분) |
| 지역별 전투 수 | 마을 18~40 · 도시 32~65 · 나라 28~37 · 행성 12~26 · 우주 10~20 |
| 지역별 패배 | 마을 4~12 · 도시 10~23 · 나라 9~13 · 행성 1~8 · 우주 0~5 |
| 우주 보스 때 군단 | 약 2,600~3,000마리 (적 약 2,900마리) |

조정한 값은 `progress.js` 맨 위(`TAME_SHARE`, `SOUL_*`, `LV_*`, `EVO_COST`, `BOSS_FACTOR`, `ENEMY_LEVEL_BONUS`)와 `battle.js`(줄 폭, 피해 배율)에 있습니다. 3,000 대 3,000 전투 계산은 한 판에 0.3초 안팎입니다.

## 구조

```
data.js        → 지역, 몬스터, 등급별 능력치·특성·이동 속도, 진화, 길들이기 확률
battle.js      → 길 위 자동 전투 (6줄, 대열, 진군, 네크로맨서 공격, 스킬, 승패). 수천 마리도 빠르게
progress.js    → 적 구성과 수, 군단(길들인 수), 길들이기, 영혼·레벨 업·진화, 보스 룰렛, 저장 데이터
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 전투 연출, 지도, 길들이기, 소환수 관리, 설정)
```
