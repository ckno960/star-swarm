# 멸망의 네크로맨서 (프로토타입)

네크로맨서가 되어 마을 → 도시 → 나라 → 행성 → 우주를 차례로 멸망시키는 자동 전투 게임입니다. 쓰러뜨린 몬스터를 길들여 소환수 군단을 키웁니다.

## 규칙

- 지역 5개, 지역마다 스테이지 10개(10번째는 보스). 보스를 쓰러뜨리면 다음 지역이 열립니다.
- **전투는 자동**입니다. 소환수를 최대 3마리 편성하면 편성 순서대로 앞에 서고, 네크로맨서는 맨 뒤에서 암흑 화살로 돕습니다. 양쪽 모두 맨 앞 상대를 때립니다.
- 네크로맨서가 쓰러지면 패배(소환수가 살아 있어도), 적을 모두 쓰러뜨리면 승리. 90초가 지나도 패배입니다.
- 네크로맨서 스킬(직접 누르거나 [자동 스킬]로 맡김)
  - **영혼 폭발**: 모든 적에게 네크로맨서 공격력 ×4 피해, 쿨타임 12초
  - **되살리기**: 쓰러진 소환수 하나를 체력 50%로 부활, 쿨타임 25초
- 이기면 지역이 무너지는 "파괴!" 연출 뒤 **길들이기!**: 그 지역 몬스터 5종 중 무작위 3마리 가운데 하나를 골라 시도합니다. 보스 스테이지에서는 보스가 반드시 후보에 들어갑니다.

| 등급 | 몸 모양 · 특성 | 길들이기 확률 |
|---|---|---|
| ★ | 점액형 · 재생 (1초마다 최대 체력 2% 회복) | 70% |
| ★★ | 짐승형 · 속공 (공격이 빠름) | 55% |
| ★★★ | 비행형 · 급습 (아무 적이나 공격) | 40% |
| ★★★★ | 인간형 · 흡혈 (준 피해 30% 회복) | 25% |
| ★★★★★ | 골렘형 · 광역 (나머지 적에게도 30% 피해) | 12% |
| 👑 보스 | 광역 | 8% |

- 길들인 몬스터는 싸웠던 레벨 그대로 합류하고, 편성에 빈자리가 있으면 바로 들어갑니다. 이미 가진 종류를 또 길들이면 그 소환수의 레벨이 오릅니다.
- 이긴 전투에 나간 소환수는 경험치를 받아 레벨이 오릅니다(최대 30). 레벨 1당 능력치 +12%.
- 다음 지역 몬스터는 기본 능력치가 2.2배라서, 지역이 바뀌면 새 지역 몬스터를 길들여 군단을 바꿔 가게 됩니다. 네크로맨서도 처음 깬 스테이지 수만큼 강해집니다.
- 처음부터 함께하는 소환수: 해골 병사

## 지역과 몬스터

| 지역 | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ | 보스 |
|---|---|---|---|---|---|---|
| 마을 | 슬라임 | 들개 | 까마귀 | 마을 경비병 | 허수아비 골렘 | 촌장 오우거 |
| 도시 | 하수구 슬라임 | 도둑고양이 | 네온 박쥐 | 도시 경찰 | 강철 골렘 | 기계 시장 |
| 나라 | 독 슬라임 | 군마 | 그리폰 | 왕국 기사 | 공성 골렘 | 폭군 국왕 |
| 행성 | 산성 점액 | 모래 도마뱀 | 익룡 | 행성 수호자 | 용암 거인 | 대지룡 |
| 우주 | 암흑 물질 | 별사냥개 | 혜성 정령 | 타락 천사 | 성운 거인 | 창조신 |

## 화면

메인(⚙ 환경설정) → 모험(멸망 지도: 지역 탭, 파괴율, 스테이지) → 전투 준비(적 미리보기, 편성 바꾸기) → 전투(❚❚ 일시정지, 속도 ×1/×2, 자동 스킬) → 파괴 → 길들이기 → 다음 스테이지. 우주 보스까지 깨면 엔딩이 나옵니다.

PC 단축키: Esc 일시정지, Q/1 영혼 폭발, W/2 되살리기.

## 실행

서버가 필요 없는 정적 페이지입니다.

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

**배포할 때**: `index.html`의 import 주소 끝 `?v=` 숫자를 하나 올립니다(세 군데). GitHub Pages 캐시 때문에 새 화면이 예전 파일을 받아 멈추는 것을 막습니다.

## 밸런스

`battle.js`의 `simulate()`로 수백 판을 돌려 맞췄습니다. "그 지역 ★~★★★ 몬스터 3마리, 레벨 = 스테이지 - 1, 자동 스킬"로 처음 도전할 때 대략:

- 1~6스테이지 거의 100%, 7~8스테이지 약 93%, 9스테이지 약 78%
- 보스: ★★~★★★★ 레벨 9면 약 26%, 레벨 10이면 약 88% (레벨을 한두 번 올리고 도전하게)
- 스킬을 전혀 안 쓰면 9스테이지 승률이 30% 정도로 떨어집니다

## 구조

```
data.js        → 지역, 몬스터, 등급별 능력치·특성, 길들이기 확률
battle.js      → 자동 전투 시뮬레이션 (공격, 특성, 스킬, 승패)
progress.js    → 스테이지 적 구성, 길들이기, 경험치, 편성, 저장 데이터
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 전투 연출, 지도, 길들이기, 소환수 관리, 설정)
```
