# 멸망의 네크로맨서 (프로토타입)

네크로맨서가 되어 마을 → 도시 → 나라 → 행성 → 우주를 차례로 멸망시키는 자동 전투 게임입니다. 쓰러뜨린 몬스터를 길들여 소환수 군단을 키웁니다.

## 규칙

- 지역 5개, 지역마다 스테이지 10개(10번째는 보스). 보스를 쓰러뜨리면 다음 지역이 열립니다.
- **길들인 몬스터는 소환할 수 있는 종류**가 되고, 같은 종류를 여러 마리 소환할 수 있습니다. 대신 **소환수 별 합에 한도**가 있습니다(★ 몬스터 1개 ~ ★★★★★ 5개, 보스 8개, 보스는 한 마리만).
- **별 한도는 네크로맨서 레벨**(처음 깬 스테이지 수 + 1)에 따라 늘어납니다: 레벨 1은 ★5, 레벨 11은 약 ★23, 레벨 31은 약 ★500, 레벨 50은 약 ★7,000.
- **적의 수는 스테이지마다 16%씩 늘어납니다**: 1스테이지 2마리 → 마을 보스 약 9마리 → 도시 보스 약 35마리 → 나라 보스 약 150마리 → 행성 보스 약 650마리 → 우주 보스 약 2,900마리. 약한 몬스터가 떼로, 강한 몬스터는 드물게 나옵니다(등급 t의 비중 1/t).
- **전투는 자동**입니다. 튼튼한 종류(골렘, 점액)가 앞, 비행형이 뒤에 서고 네크로맨서는 맨 뒤에서 암흑 화살로 돕습니다. 양쪽 모두 맨 앞 상대를 때립니다.
- **자동 편성**(기본 켜짐)은 전투 전마다 별 한도를 가장 알차게 채웁니다. [소환수] 화면에서 종류별 마리 수를 직접 바꾸면 자동 편성이 꺼지고, 다시 누르면 켜집니다.
- 네크로맨서가 쓰러지면 패배(소환수가 살아 있어도), 적을 모두 쓰러뜨리면 승리. 90초가 지나도 패배입니다.
- 네크로맨서 스킬(직접 누르거나 [자동 스킬]로 맡김)
  - **영혼 폭발**: 모든 적에게 네크로맨서 공격력 ×3 피해, 쿨타임 12초
  - **되살리기**: 쓰러진 소환수를 최대 10마리, 체력 50%로 부활, 쿨타임 25초
- 이기면 지역이 무너지는 "파괴!" 연출 뒤 **길들이기!**: **이번 전투에서 만난 적 종류 중** 최대 3가지 가운데 하나를 골라 시도합니다. 보스 스테이지에서는 보스가 반드시 후보에 들어갑니다.
- 길들이기 결과가 나오면 **"이 스테이지를 다시 할까요?"** 와 함께 [다시 하기] [다음 스테이지] [지도로]를 고릅니다.

| 등급 | 몸 모양 · 특성 | 길들이기 확률 |
|---|---|---|
| ★ | 점액형 · 재생 (계속 조금씩 회복) | 70% |
| ★★ | 짐승형 · 속공 (공격이 빠름) | 55% |
| ★★★ | 비행형 · 급습 (아무 적이나 공격) | 40% |
| ★★★★ | 인간형 · 흡혈 (준 피해 30% 회복) | 25% |
| ★★★★★ | 골렘형 · 광역 (맨 앞과 그 뒤 2마리에게 30% 피해) | 12% |
| 👑 보스 | 광역 | 8% |

별이 많은 몬스터일수록 별 하나당 힘이 조금 더 큽니다(√(체력×초당 피해) ≈ 17 × 별^1.15). 그래서 길들이기 어려운 강한 몬스터를 모을수록 같은 한도에서 군단이 강해집니다.

- 길들인 몬스터는 싸웠던 레벨 그대로 합류합니다. 이미 가진 종류를 또 길들이면 그 종류의 레벨이 오릅니다.
- 이긴 전투에 나간 종류는 경험치를 받아 레벨이 오릅니다(최대 30, 같은 종류는 모두 같은 레벨). 레벨 1당 능력치 +12%.
- 다음 지역 몬스터는 기본 능력치가 2.2배라서, 지역이 바뀌면 새 지역 몬스터를 길들여 군단을 바꿔 가게 됩니다. 네크로맨서도 처음 깬 스테이지 수만큼 강해집니다.
- 처음부터 함께하는 소환수: 해골 병사

## 지역과 몬스터

| 지역 | ★ | ★★ | ★★★ | ★★★★ | ★★★★★ | 보스 |
|---|---|---|---|---|---|---|
| 마을 | 슬라임 | 들개 | 까마귀 | 마을 경비병 | 허수아비 골렘 | 촌장 오우거 |
| 도시 | 하수구 슬라임 | 도둑고양이 | 네온 박쥐 | 도시 경찰 | 강철 골렘 | 기계 시장 |
| 나라 | 독 슬라임 | 군마 | 그리폰 | 왕국 기사 | 공성 골렘 | 폭군 국왕 |
| 행성 | 산성 점액 | 모래 도마뱀 | 익룡 | 행성 수호자 | 용암 거인 | 대지룡 |
| 우주 | 암흑 물질 | 별사냥개 | 혜성 정령 | 타락 천사 | 성운 거인 | 창조신 |

## 화면

메인(⚙ 환경설정) → 모험(멸망 지도: 지역 탭, 파괴율, 스테이지) → 전투 준비(적 종류별 수, 내 군단, 편성 바꾸기) → 전투(❚❚ 일시정지, 속도 ×1/×2, 자동 스킬, 남은 아군·적 수) → 파괴 → 길들이기 → 다시 하기 / 다음 스테이지. 우주 보스까지 깨면 엔딩이 나옵니다.

[소환수] 화면: 별 사용량 / 한도, 종류별 마리 수(−, +, 최대), 자동 편성, 이름을 누르면 능력치.

PC 단축키: Esc 일시정지, Q/1 영혼 폭발, W/2 되살리기.

## 실행

서버가 필요 없는 정적 페이지입니다.

```
python3 -m http.server 8000   # 이 폴더에서 실행 → http://localhost:8000
node --test                   # 로직 테스트
```

**배포할 때**: `index.html`의 import 주소 끝 `?v=` 숫자를 하나 올립니다(세 군데). GitHub Pages 캐시 때문에 새 화면이 예전 파일을 받아 멈추는 것을 막습니다.

## 밸런스

`battle.js`의 `simulate()`로 스테이지마다 수십 판씩 돌려 맞췄습니다. 가정: "앞 지역 몬스터 5종은 레벨 12, 이번 지역은 지금까지 나온 ★~★★★ 종류를 레벨(스테이지 - 1)로 가짐, 자동 편성, 자동 스킬"로 처음 도전.

| | 마을 | 도시 | 나라 | 행성 | 우주 |
|---|---|---|---|---|---|
| 1~5스테이지 | 93~100% | 98~100% | 100% | 96~100% | 100% |
| 9스테이지 | 50% | 73% | 68% | 75% | 81% |
| 보스 | 35% | 30% | 60% | 71% | 63% |
| 아군 / 적 (보스 스테이지) | 11 / 9 | 41 / 35 | 178 / 149 | 783 / 654 | 3,396 / 2,882 |

- 이번 지역 몬스터 레벨이 2 높으면 보스 승률이 57~100%로 오릅니다(다시 하기로 키우는 길).
- 스킬을 안 쓰면 보스 승률이 10~43%로 떨어집니다.
- 군단이 클수록 수가 조금만 많아도 승패가 크게 갈려서, 별 한도는 적 수와 같은 비율로 늘리고 약간의 덤만 얹었습니다(`progress.js`의 `CAP_*`).
- 전투는 10~20초. 3,000 대 3,000 전투 계산은 한 판에 수십 ms입니다.

## 구조

```
data.js        → 지역, 몬스터, 등급별 능력치·특성·별, 길들이기 확률
battle.js      → 자동 전투 시뮬레이션 (공격, 특성, 스킬, 승패). 수천 마리도 빠르게
progress.js    → 적 구성과 수, 별 한도, 군단 편성(자동 편성), 길들이기, 경험치, 저장 데이터
game.test.js   → 로직 테스트
index.html     → 화면 전체 (픽셀 그림, 전투 연출, 지도, 길들이기, 소환수 관리, 설정)
```
